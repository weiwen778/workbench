# 上线性能测试与代码审查（2026-10-31）

本轮完成了代码审查、修复、隔离环境压测、数据库升级验证和浏览器回归。修复前 100 并发出现连接池超时；修复后同负载零错误，吞吐由 7.81 提升到 96.68 请求/秒。满负载 P99 约 1.4 秒，因此不能声称 100 并发达到 P99 <300ms。

## 测试范围与环境

- WSL：Python 3.10、PostgreSQL 14，单 Uvicorn 进程、无 reload，API 限定使用两个逻辑 CPU；同机独立数据库、独立账号与端口。宿主共 12 逻辑 CPU、约 25GB 内存，不能据此推算云端总容量。
- 云端：2 CPU、约 1.87GB 内存，候选镜像 Python 3.12 / PostgreSQL 16。临时 API 限制 1 CPU / 512MB，测试数据库仅复制线上结构再导入模拟数据，线上业务数据未参与压测。
- 数据量：一年模拟经营数据，11 张表、5,004 条记录、9,672 条打卡、240 条待办，笔记/标签/文件夹另加各 40 条分类数据以触发原 N+1 路径。80% 读、15% 更新专用模拟便利贴、5% 看板聚合；不调用付费翻译服务。
- 不使用本地用户库覆盖云端。对线上仅做迁移、健康与静态资源验证。

## 审查发现与修复

1. **连接池与线程池饥饿**：大量同步请求先占用线程，再等待数据库连接，造成超时。增加异步入口限流，在同步依赖运行前排队；默认池 5+10，业务并发 13，预留连接。重型导入/导出独立限制为 2。健康检查绕过排队，超时明确返回 503 和 Retry-After，取消请求释放名额。每个进程独立计算容量，不盲目增加 worker。
2. **阻塞事件循环**：上传、导入预览原先在 async 路由执行同步磁盘、ORM、解析。改为同步路由交由 FastAPI 线程池；不要求为同步路由强行更换 asyncpg。
3. **无界导入解析**：文件读取按上限截断，Excel 压缩展开体积上限 64MiB、最多 5,000 项、20 工作表、10,000 数据行/表、50 列、累计 500,000 单元格。CSV/JSON/XLS 同样限制规模，及时关闭资源。超限返回业务错误；格式化到极远行的 Excel 可能触及上限。
4. **N+1 查询与大响应**：笔记文件夹/标签、待办清单计数改为分组 SQL；笔记标签批量读取。新增可选 summary=true，前端列表只取摘要，正文编辑仍独立获取完整内容，默认 API 保持完整正文兼容。全文搜索仍查询正文。
5. **打卡与看板重复计算**：打卡历史与规则按目标批量处理，首次生成使用 ON CONFLICT 保证并发幂等；保留旧完成快照与缺口补齐语义。看板按请求缓存表元数据，纯计数改 SQL COUNT。对 JSON 投影进行了实测，因当前场景更慢，保留单次 JSON 读取；无跨请求缓存导致数据过期。
6. **查询索引**：新增 notes(folder_id,deleted_at,updated_at) 与 data_records(table_id,deleted_at,id) 复合索引。不是所有搜索/统计都能走索引，LIKE 正文和 JSON 聚合仍随数据量增长。
7. **部署构建污染**：Docker 上下文排除运行数据、密钥、缓存、测试产物，增加只打包已验证前端产物的部署方式，避免 2GB 云机重复 Node 构建。

数据库迁移：云端原 b92f30a6e741 → c03a81df2742（打卡名称）→ d14e62a583b7（索引），均为追加性变更。保持现有加密密钥、账号、数据库卷与附件卷。

## 回归证据与限制

- SQLite、PostgreSQL 14、云端 PostgreSQL 16 各 191 项后端测试通过；包含 12 项新增性能契约回归，覆盖排队、取消、导入边界、常量查询次数、正文兼容和打卡幂等。
- 浏览器通过分类导航、笔记保存失败/切换保护、打卡名称持久化、便利贴移动/恢复、看板主题与路由、侧栏手风琴/刷新收起、移动端、PDF 延迟加载、设置/回收站；图片模块验证像素输出、格式转换、裁剪、缩放、马赛克、撤销、ZIP 与无图片上传请求。
- 只剩 Starlette 测试客户端的 httpx 弃用提示，未为消除提示升级生产依赖。
- 本轮不是安全渗透测试；不包含 1,000 并发、跨地域网络压测、真实大量附件上传、4～8 小时内存趋势或全链路外部翻译耗时验证。长期增长仍需关注 JSON 聚合、全文搜索与附件体积。

## 复现

仅使用独立测试数据库和测试服务。需要 Python 测试环境中的 httpx / psycopg、PostgreSQL 和已安装的前端依赖；避免 --reload。先用 `python scripts/demo_year.py seed --preview` 生成独立 SQLite 模拟库与 manifest，再创建空的 `workbench_element_test_*` PostgreSQL 库及专用账号。

在未跟踪的私有 JSON 中配置 target（结果目录）、api_pid（测试 API 进程）、databases.performance（回环地址测试 DSN）、username（perf- 前缀）、password。文件 chmod 600，不提交 Git。将 WB_DATABASE_URL、WB_ADMIN_USERNAME、WB_ADMIN_PASSWORD、WB_STORAGE_DIR 设置为同一测试环境。

```bash
server/.venv/bin/python scripts/perf_seed.py --runtime /private/runtime.json --source-sqlite .run/demo-year-preview/preview.sqlite3 --manifest .run/demo-year-preview/manifest.json
cd server && .venv/bin/alembic stamp head && .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 18746
# 在另一个终端运行（同一测试环境）
server/.venv/bin/python scripts/perf_load.py --runtime /private/runtime.json --name slo --duration 60 --concurrency 10 --rps 40
server/.venv/bin/python scripts/perf_load.py --runtime /private/runtime.json --name soak --duration 14400 --concurrency 10 --rps 28
```

Seeder 只允许回环地址且名称以 workbench_element_test 开头的库，目标表必须为空；仅复制 manifest 标记的模拟业务实体，不复制真实登录会话。数据库结构用模型创建后 stamp head，不能对已有生产数据库如此处理。浏览器脚本也应使用独立空测试库；可指定 CHROME_PATH 和 WB_BASE。原始公开结果见 [results.json](performance/2026-10-31/results.json)，不包含账号密码或用户数据。

参考：[FastAPI 同步/异步路由](https://fastapi.tiangolo.com/async/)、[按需组件注册](https://github.com/unplugin/unplugin-vue-components)。生产当前单进程，增加进程前应计算 worker × (pool_size + max_overflow) 并为维护、其他应用、监控留余量；本云机与其他服务共用资源，不采用固定 CPU×2+1 公式。
