# 设置与页面层级整理

本轮只更新本地 WSL：<http://localhost:18081/settings>。不推送 GitHub，不部署云端，不需要数据库迁移。

## 页面层级

页面名称统一由顶部导航显示。增强/经典表格、表格目录、数据可视化、待办、笔记和便利贴清理重复标题；回收站作为设置子页面显示一次标题。表格切换到经典视图时只保留经典工具栏，返回增强视图会重新载入当前数据。行数放在工具栏，底部保留选区与汇总信息。

## 设置分组

| 分组 | 地址 | 可以做什么 |
| --- | --- | --- |
| 外观与动效 | /settings | 浅色/深色预览、预设/自定义强调色、恢复默认颜色、减少动态效果 |
| 导航与命名 | /settings/navigation | 集中修改两类打卡名称，一次保存，填入默认值 |
| 账号与安全 | /settings/account | 修改密码、校验两次输入、退出当前设备 |
| Agent 接入 | /settings/agents | 创建/撤销令牌、复制接入说明、查看写入记录 |
| 翻译服务 | /settings/translation | 直接配置密钥/模型、启用/停用、连接测试、清除密钥 |
| 回收站 | /settings/trash | 按类型查找、恢复和永久清理；原 /trash 地址继续重定向 |
| 系统信息 | /settings/system | 检查服务和数据连接、失败重试、时区及数据处理说明 |

设置分类支持搜索。桌面显示侧边分类，手机显示可换行分类入口。主题与强调色保存到账号；减少动态效果仅保存在本设备，系统的减少动态效果偏好始终生效。

主题/颜色保存失败会还原原值并显示原因；保存期间禁止重复提交。导航命名、密码、翻译密钥以及未保存的新令牌在离开时提醒，未成功提交的输入不会被清空。密码修改后保留当前登录，其他设备需重新登录。退出失败时不会先清空客户端登录状态。

翻译配置与翻译页的「服务设置」共用组件。已有密钥留空保留，保存后清空明文输入；连接测试只测试已保存配置，可能消耗服务额度。清除密钥需要明确确认。密钥不存入本机偏好设置。

## 设置分类切换稳定性修复

分类切换使用同一个设置外壳和导航实例，关闭设置外壳的页面位移动画；滚动区域预留固定滚动条空间，选中项保持相同字重。右侧内容切换后清理已明确放弃的表单输入、回到顶部，系统状态仍会在进入时检查；分类搜索保留，未保存与保存中守卫继续生效。

桌面 1560×1000、手机 390×844 分别连续切换七个分类两轮。逐帧采样共 736 次：外壳、导航和路由框架均未重建，无容器动画，导航 x/y/宽高及内容区可用宽度变化均为 0px，透明度保持 1。原有 20 项设置浏览器检查再次通过。构建包含 Vue 类型检查，git diff --check 通过。

复测：隔离服务启动后执行 `WB_BASE=http://127.0.0.1:18747 node e2e/settings-stability.mjs`（Node 依赖位于 e2e；默认输出路径相对于执行目录）。


## 大屏空间利用

设置外壳取消 1260px 居中宽度上限，使用工作区全部可用宽度；分类栏固定 200px，收紧标题、分类和卡片的间距。Agent 写入记录的最大高度改为按窗口剩余空间计算，窗口缩放或令牌行变化时重新测量；数据较少时按实际行数显示，不填充空白行。

在 2319×1235 的测试窗口中，工作区可用宽度 2117px，设置外壳宽度同为 2117px，Agent 卡片 1861px、记录区 819px 高；调整至 1560×900 后记录区缩至 459px。390px 手机无横向页面溢出。桌面/手机的分类切换位置偏移仍为 0px，20 项设置功能回归通过。仅更新本地前端，无数据库迁移或业务数据改动。

复测用例：`e2e/settings-space.mjs`。其中令牌及 40 条历史列表使用浏览器模拟响应，未新增真实业务数据。
