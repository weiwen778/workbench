# 全模块 UI 与功能巡检报告（2026-11-15）

巡检对象：`~/workbench_element`（个人工作台），服务实例 `http://127.0.0.1:18080`，`WB_ENV=production` + PostgreSQL。

## 1. 范围与方法

| 维度 | 做法 | 覆盖量 |
| --- | --- | --- |
| 代码审查 | 逐模块读路由/服务/页面源码，扫高危调用（`eval`/`exec`/`subprocess`/裸 SQL）、鉴权装饰器覆盖、容器与反代配置 | 26 个 API 分组 / 144 个接口；27 个 router、29 个 service、22 个页面 |
| 页面渲染 | Playwright 登录后遍历全部路由，桌面 1440 / 平板 820 / 移动 390 三档截图，采集 console、失败请求、横向溢出、越界元素、坏图、文字裁切 | 31 个路由 × 2 档 + 8 页平板档 = 70 张截图 |
| 窄屏 | 360 / 320 两档复测（iPhone SE 级别） | 23 个路由 × 2 档 |
| 暗色主题 | 切换主题后对 8 个主力页面截图比对 | 8 张 |
| 弹窗 | 逐个打开 16 个关键弹窗/抽屉（新建表格、新建看板、管理打卡项目、新建便利贴、添加网址、新建笔记、新建白板、任务中心、统一搜索、移动端新建表格等），量测弹窗尺寸与内容溢出 | 16 个 |
| 主流程 | 每个模块跑一次「创建 → 校验（UI + API 双向） → 清理」闭环 | 12 条 |
| 自动化 | 后端 `pytest` 全量、前端 `tsc -b` 类型门槛、`npm run build` | 全量 |

巡检脚本已入库：`e2e/audit-run.sh`（从 `server/.env` 取管理员口令，不在命令行明文出现）、`e2e/audit-sweep.mjs`（全路由巡检）、`e2e/audit-deep.mjs`（窄屏 + 弹窗）、`e2e/audit-flows.mjs`（12 条主流程）、`e2e/audit-deepflow.mjs`（导出/导入/工作簿/Agent/PDF 深水区）、`e2e/audit-dark.mjs`（暗色全站 + 对比度）、`e2e/audit-cleanup.mjs`（清理巡检数据）。

```bash

bash audit-run.sh audit-dark.mjs       # 暗色 23 路由 + 对比度探针
# 或 npm run audit:sweep / audit:deep / audit:flows / audit:cleanup
```

## 5. 未改项与已知限制

- **移动端回收站表格**：列多，窄屏需横向滚动才能看到「删除时间 / 操作」。DataGrid 自带滚动条，页面无横向溢出；如果要彻底改，需要按断点隐藏列，涉及表格组件公共逻辑，本次不动。
- **`/checkins` 列表 GET 内做周期补齐并写库**：架构取舍，改动面大，README 已记录。
- **`maintenance.py:69` 清理失败日志缺 `exc_info`**：只影响排障信息量。
- **长文本预览**：笔记列表、表格卡片说明使用 2 行 `line-clamp`，属设计内的截断，不是缺陷。
- **演示数据**：库里的「【模拟】」条目与 `DEMO-YEAR-20261031` 说明来自模拟数据脚本，不是显示错误。
