# 操作栏统一规范

## 背景

各模块原本把按钮放在页面不同位置：有的新建在左上，有的在右下；刷新有时是图标、有时在更多菜单；待办的新建靠输入框，笔记的操作在左侧列表头。切换模块时需要重新寻找按钮，增加使用成本。

本次把所有模块页面的顶部操作栏统一为同一套槽位，主操作永远在右上角。

## 槽位

```
[左侧：上下文/筛选/标签页]                    [右侧：筛选 → 刷新 → 更多 → 主操作]
```

- 左侧放当前页面的上下文：统计、标签页、语言选择、打卡周期等。
- 右侧动作区固定在右侧，从右往左依次是：
  1. **主操作**：当前页面最主要的创建/提交动作，`variant="contained"`。
  2. **更多**：低频操作收进图标菜单。
  3. **刷新**：图标按钮，固定在更多左侧。
  4. **筛选/搜索/视图**：搜索框、排序、视图切换、次要按钮。
- 左侧与右侧之间自动留白；窄屏换行时，右侧动作区仍保持右对齐。
- 详情页返回按钮放在左侧上下文，主操作仍在右上角。
- 没有全局主操作的工具页（二维码、文档工作台）允许只保留上下文和次要操作，但不再把主操作移到页面中部。

## 主操作对照

| 模块 | 主操作 |
| --- | --- |

| 打卡资料 | 添加任务 |
| 数据可视化 | 新建看板 / 添加图表 |
| 表格 | 新建表格 / 添加一行 |
| 待办 | 新建清单 |
| 笔记 | 新建笔记 / 编辑 |
| 便利贴 | 新建便利贴 |
| 网址导航 | 添加网址 |
| 白板 | 新建白板 / 保存 |
| 图片处理 | 选择图片 / 导出当前图片 |
| 格式转换 | 添加文件 |
| 翻译 | 翻译 |
| 取色与颜色格式 | 选择图片 |
| 回收站 | 清理已到期 |

## 实现

`web-react/src/ui/common.tsx` 新增 `ModuleToolbar`，通过 `info`、`filters`、`onRefresh`、`more`、`primary` 五个槽位生成固定顺序，避免各页面手写顺序再次分散。刷新按钮由组件统一渲染，加载中自动显示进度圈。

槽位带有 `data-toolbar-slot` 属性，操作栏带有 `data-module-toolbar="true"`，供浏览器检查断言位置和顺序。

已接入的页面：打卡、打卡资料、看板、表格列表/详情、待办、笔记列表/阅读、便利贴、网址、白板列表/编辑器、图片处理、格式转换、翻译、取色、二维码、文档工作台、回收站。

## 验证

- `npm run typecheck`、`npm run build` 通过。
