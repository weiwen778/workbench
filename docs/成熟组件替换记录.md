# 成熟组件替换记录（2026-11-03）

本轮替换范围：分栏、ZIP 打包、图片裁剪、Markdown 编辑、汇总/透视。基础表单、PDF.js、Univer、ECharts 等已有成熟依赖继续保留。

| 功能 | 采用实现 | 保留的业务逻辑 |
| --- | --- | --- |
| 主侧栏、翻译收藏/历史分栏 | Element Plus Splitter | 宽度记忆、边界、键盘调整、双击恢复；侧栏 Esc 取消拖动 |
| 图片批量 ZIP | fflate，STORE 模式 | 图片生成、文件命名与导出；不上传图片 |
| 图片裁剪 | Cropper.js 2 | 原图尺寸、旋转/翻转、比例与像素输入、撤销与导出；组件负责选区拖动和缩放 |
| 笔记正文 | CodeMirror 6 + Markdown | 纯文本 Markdown 存储、自动保存、版本冲突、粘贴图片、分类切换保护 |
| 汇总/透视 | VTable PivotTable | Decimal.js 精确数值聚合、现有字段显示、点击联动原始明细 |

## 使用入口

- 分栏可直接拖动；键盘左右调整；双击恢复默认宽度。
- 笔记 Ctrl / Command + F 打开编辑器内查找；撤销记录按笔记隔离。
- 图片处理页开启裁剪，拖选、使用边角调整范围，中间手柄可移动选区；其余图片工具和本地导出继续可用。
- 表格 → 更多操作 → 汇总与透视。通过现有 workspace 接口获取整张表的记录，不使用当前页代替全部数据。该接口当前上限仍为 10000 行，超过时明确提示；此轮不改变后台容量边界。

## 验证

使用独立临时 SQLite 数据库和临时 HTTP 服务，未写业务库。

- `e2e/components-migration.mjs`：两个分栏、笔记自动保存/查找/撤销隔离/刷新、透视总计和点击明细联动、手机布局。
- `e2e/folder-navigation.mjs`：笔记/待办分类、新建/重命名/删除、保存失败仍保留输入、保存中继续输入、切换分类保护、手机与折叠导航；编辑器选择器已适配 CodeMirror。
- `e2e/image-tools.mjs`：图片像素、裁剪、旋转翻转、调色、撤销重做、PNG/JPEG/WebP、批量 ZIP、拼图、手机与本地处理边界；通过 esbuild 打包测试模块以解析 fflate 依赖。
- ZIP 重新用 Python zipfile 解包检查：中文文件名、批量文件名、CRC 校验通过。
- `e2e/sidebar-resize.mjs`：宽度恢复、最小/最大值、Esc 取消、键盘步进、双击恢复、折叠/展开、窄屏及主题。
