# 工作簿快捷键

只在自由工作簿激活、无对话框且非输入法组合输入时处理工作台级快捷键。切换模式或离开后不会继续拦截。

| 快捷键 | 行为 |
|---|---|
| Ctrl+S / Command+S | 提交正在编辑的单元格并保存到工作台 |
| F12 | 输入文件名，下载独立Excel文件；不会替换工作台文档 |
| Ctrl+P / Command+P | 生成当前工作表已使用区域的可打印内容，调用浏览器打印（可另存PDF） |
| Ctrl+W | 若浏览器向页面派发此按键，先保存，再关闭工作簿并返回原始表 |
| Ctrl+Z / Ctrl+Y | 编辑器原生撤销、重做 |
| Ctrl+A | 编辑器原生全选；编辑文本时保留文本全选 |
| Ctrl+C / Ctrl+X / Ctrl+V | 编辑器原生复制、剪切、粘贴 |
| Ctrl+F / Ctrl+H | 打开编辑器的查找/替换面板 |
| Ctrl+K | 打开原生超链接编辑面板；链接数据随工作簿保存 |

浏览器可能保留Ctrl+W、F12、部分Mac组合键；网页不能保证拦截浏览器保留键。“更多”菜单提供另存为、打印、关闭工作簿、查找、替换和插入超链接的入口。Ctrl+W的关闭行为只通过页面事件回归验证，不宣称可以阻止所有浏览器关闭标签页。

打印是当前子表的格式化值表格，不打印应用导航，也不是WPS的完整分页排版引擎；使用范围超过10万格时提示缩小范围。用户文本在打印HTML中转义，打印后或组件退出时清理临时iframe。没有真实向打印机发送测试任务。

依赖增加与现有Univer版本一致的1.3.0超链接预设。浏览器回归包括保存、未完成编辑提交、失败重试、原生撤销重做、复制剪切粘贴持久化、全选、查找替换、超链接持久化、命名Excel下载、打印内容与调用、文档内关闭和作用域释放。仅WSL本地。

## 首次打开回归

公网验收发现，Univer查找Provider默认在Steady阶段延迟初始化，导致初次按Ctrl+F/H没有查找界面。首次调用时显式取得同一个SheetsFindReplaceController完成初始化，并同步工作簿焦点；隐藏时释放焦点。新增不先点击单元格的首个查找/替换回归，随后完整快捷键测试通过。
