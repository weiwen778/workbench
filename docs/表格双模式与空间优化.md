# 原始 Element 表格与自由工作簿

原始表使用原有 Element Plus 表格组件，包括服务端分页、筛选、排序、列设置、行编辑、删除、导入导出。页面不使用增强 Canvas 表格。自由工作簿仍独立保存。

顶部固定为44px高，两段切换按钮使用固定宽度；两种模式复用右侧工具栏位置，窄屏时只在操作区内横向滚动。原始表与访问过的工作簿保留实例，以维持页码、筛选、滚动和工作簿状态。切换前检查工作簿保存结果，失败时保留原模式。

原始表默认收起筛选编辑区。工作簿通过Teleport把状态、导入、导出和更多操作放入统一工具栏。说明不常驻显示。只有打开工作簿时才请求其完整来源数据，原始表不受增强表格整表载入行数限制影响。

浏览器回归覆盖：确认实际Element DOM与服务端分页、固定模式按钮坐标与44px栏高、返回时页码和滚动保留、行编辑/列设置/导出入口、服务端筛选、工作簿重复切换与导出、窄屏边界。另覆盖工作簿冲突、草稿恢复和深色模式。仅在WSL本地调整。
