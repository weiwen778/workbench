### 3.2 关键规则的实现方式（便于你复核）

- **周期与锁定**：实例以 `(事项, 周期起点)` 唯一约束去重；每次读取按当前周期补齐，停机遗漏的历史周期以「未完成、只读」补出；锁定判断用 `period_end <= 今天`，所以周末、月末 00:00 之后不能再打勾或取消。
- **修改与快照**：实例保存当时的标题/说明/分组/对象名；改事项只更新「当前周期 + 未完成 + 未锁定」的实例；已完成实例保留旧内容，取消时再同步最新要求（验收 A18/A19 已覆盖）。
- **父子待办**：状态不再独立存储，而是由子任务推导；有子任务时父任务勾选被禁用并给出原因；新增未完成子任务会让父任务重新打开；删掉最后一个子任务后父任务保留当时状态并恢复手动勾选。
- **导入原子性**：预览只读不写；确认时先整批校验，任何一行有错就整批拒绝并返回原 Excel 行号与列名；同一任务重复确认直接返回上次结果，不会重复追加。
- **翻译凭据**：只有服务端持主密钥才能加密保存；读取只返回 `abcd****xy` 形式；缺主密钥时接口返回 `CREDENTIAL_KEY_MISSING` 并提示去配置 `WB_ENCRYPTION_KEY`，而不是让保存按钮静默失效。
- **文件生命周期**：上传先落暂存，记录/笔记保存时才建立引用并把文件标记为 bound；只有所有引用（含历史版本、回收站）都消失才物理删除。

## 5. 本轮改出来的问题（真实缺陷，均已修复）

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| 打了勾但清单里没有事项 | 补齐实例时只遍历「已结束」周期，当前周期被跳过 | 当前周期单独补齐，历史周期走回填 |
| 侧栏收起按钮点了之后仍然展开（栏内无收起按钮） | 展开态侧栏缺少 `collapsible` 属性 | 传入 `collapsible`，收起后进入图标栏 |
| 所有页面内容只占屏幕一半，右侧大片空白 | `.wb-main` 少了 `flex: 1`，作为 flex 子项被压到内容宽度 | 补齐 `flex: 1 1 auto`；侧栏 `flex: 0 0 auto` |
| 事项修改记录接口 500 | 用了不存在的 `created_at` 字段 | 改用 `effective_from` 排序 |
| 待办没有子任务时永远加不了子任务 | 子任务输入区只在已有子任务时渲染 | 增加「＋」入口，输入区按需展开 |
| 归档对象后当天清单仍显示旧记录 | 归档锁定的实例仍参与当天统计 | 当天清单与统计排除「对象已归档」锁定项，历史里保留 |
| 翻译保存自定义服务地址被丢弃 | 保存时只允许凭据字段，`base_url` 被过滤 | 允许 `base_url` 并把 HTTPS/本机限制放在请求前校验 |
| 上传文件名里的空格变成下划线 | 文件名清洗正则过严 | 保留空格与括号，仅替换危险字符 |
| 匿名写接口返回 403 而不是 401 | CSRF 校验先于鉴权执行 | 没有会话 Cookie 的请求跳过 CSRF，交给鉴权返回 401 |
| 20 MB 边界附近的暂存过期时间不对 | 暂存 `expires_at` 写成了当前时间 | 改为 `now + 24h` |
| 导出两次文件名冲突（唯一键报错） | 导出文件名只精确到秒 | 追加 8 位随机串 |
| 恢复笔记时「原文件夹已删」提示不出现 | 删文件夹时把回收站里的笔记也置空了 | 只调整活动笔记，恢复时结合快照判断 |

另外按 CSS 变量规范做了两处修正：禁用但仍勾选的复选框改用 `--el-checkbox-disabled-checked-*` 变量，保证「完成的父任务」勾选可见；已完成行淡化从 0.62 提到 0.78（暗色 0.86），避免看不清。

## 7. 需要你拍板的三件事

1. **正文里的附件预览**：现在是浏览器内联（图片、PDF 直接用浏览器阅读器），没有自建 PDF.js 的分页/缩放/适宽工具条（PRD 8.1.5 要求）。要不要补一个真正内嵌的阅读器？补它需要打包 worker 与字体，前端体积会涨。
2. **回收站与暂存文件的自动清理**：目前提供接口（`POST /trash/purge-expired`）但没有内置定时任务，需要外部 cron 或部署时加一行计划任务。要不要我在 API 里加一个轻量后台调度（每小时一次）？
3. **生产凭据**：`WB_ENCRYPTION_KEY` 必须先生成并长期保存，丢了旧翻译凭据就解不开；管理员密码也要换。这一步只能你来做，我不替你生成正式密钥。

详细遗留问题与优先级见 `docs/待办清单.md`。
