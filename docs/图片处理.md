# 图片处理（纯前端）

入口：主导航「图片处理」，与「翻译」同级，地址 `/images`。桌面、折叠侧栏与手机抽屉均提供入口。

## 日常功能

- 添加图片：选择文件、多图拖放、粘贴截图；队列内可切换、勾选、移除与调序。
- 尺寸：拖选或按像素裁剪，自由、原图及常用比例；旋转、翻转、锁定比例缩放；商品主图、竖版和横版尺寸预设；拉伸、留白与铺满适配；背景色、透明底、留白和圆角。
- 调色：亮度、对比度、饱和度、黑白、复古、模糊和快捷滤镜；按颜色容差与边缘柔化进行纯色去底，适合白底或绿幕，不提供 AI 主体识别。
- 标注：文字水印、角落 / 居中 / 平铺、字号、颜色、透明度与角度；画笔、画框和区域马赛克。
- 拼图：使用已勾选图片的编辑效果，按队列顺序生成网格、横图或竖图；设置每格尺寸、列数、间距、底色和适配方式。
- 导出：PNG、JPEG、WebP；JPEG / WebP 质量控制；可选目标 KB；文件名前缀；逐张下载、应用同一套编辑参数到已选图片、批量 ZIP 下载。
- 编辑历史：每张独立保存最近 30 个状态；按钮撤销 / 重做，也支持 Ctrl / Command + Z、Shift + Z 与 Ctrl / Command + Y。文本输入框保留浏览器自身的撤销行为。

## 使用说明

图片始终通过 File、Blob URL 和 Canvas 在浏览器内处理。此模块不引入服务端代码、图片接口、上传请求、远程处理服务、CDN、数据库或浏览器持久存储。ZIP 在前端生成，采用 UTF-8 文件名与 CRC32 校验。页面外壳仍使用工作台既有登录及导航机制。

离开页面或刷新会清空素材和编辑历史，请先下载。浏览器可以读取的常见图片可导入；无法读取的 HEIC 等格式会提示转换。GIF 等动图按当前静态画面导出，SVG 也会转为位图。Canvas 导出不会保留原图的 EXIF / GPS 等元数据。JPEG 不支持透明，透明区会填入所选底色；PNG / WebP 可保留透明。

设置目标大小后，先尝试降低 JPEG / WebP 质量，仍超限时缩小尺寸；PNG 通过缩小尺寸减小体积。实际像素和文件大小会在完成后显示，极小目标未满足时会明确提示。纯色去底会移除画面内所有相近颜色；重要隐私建议用不透明画笔覆盖。

为控制浏览器内存：每批最多 30 张、合计 100 MB，单张最多 20 MB / 4000 万像素，队列解码总像素最多 1.2 亿；导出每边最多 8192 像素、合计最多 2400 万像素。预览会缩小以保持操作流畅，正常导出使用实际尺寸。

## 开发与验证

实现：`web/src/views/ImageToolsView.vue`、`web/src/utils/image-tools.ts`。没有新增依赖。图片编辑引擎没有 API 客户端或网络调用。

在隔离的本地测试服务上运行：

```bash
cd e2e
WB_BASE=http://127.0.0.1:18746 node image-tools.mjs
# 可设置 CHROME_PATH；需要已安装 web / e2e 开发依赖及测试管理员账号。
```

脚本通过 Playwright 本地拦截提供引擎测试模块，不往正式构建添加测试入口。验证像素、裁剪坐标、旋转与翻转、透明底与圆角、去底、调色、画笔、水印、拼图尺寸、JPEG 填底、体积控制、格式 MIME、尺寸限制、实际下载、独立历史、撤销与重做、批量应用、空选区、损坏文件、SVG 隔离、拖放、手机布局和网络请求。输出在 `.run/image-tools-e2e`。测试只通过现有登录接口使用测试账号，所有图片都在前端生成和处理。
