# 取色与二维码工具

两个纯前端本地工具，均已接入现有侧栏和工作台主题。

| 工具 | 入口 | 页面 |
| --- | --- | --- |
| 取色与可读性检查 | 侧栏「取色对比」；图片处理页「取色 / 对比度」按钮 | `/color` |
| 二维码与条码 | 侧栏「二维码条码」 | `/codes` |

处理全部在浏览器完成，不上传图片、文字或 Wi-Fi 信息，也没有新增后端接口。切换页面/图片时会释放上一张图片和预览资源。

## 取色与可读性检查

### 图片取色
- 支持拖入、文件选择、`Ctrl / Command + V` 粘贴；复用图片转换工具的本地解码和 EXIF 方向处理。
- 预览支持 10%–400% 缩放和滚动；鼠标移动显示 15×15 像素放大镜，点击锁定取样。
- 取样按图片实际像素坐标计算，兼容缩放、滚动、留白和高 DPI（已在 devicePixelRatio=2 下验证）。
- 显示 HEX（含透明度时为 8 位）、RGB/RGBA、HSL/HSLA 和透明度百分比；可分别复制。
- 取样可直接设为前景或背景；全透明像素会明确标注并禁止设置为实色。
- 手动输入支持 `#RRGGBB`、`#RRGGBBAA`、`rgb()/rgba()`、`hsl()/hsla()`，也可使用原生颜色选择器。
- 单张图片最多 2400 万像素；超出时提示先缩小。

### 可读性检查
- 前景/背景手动输入或图片取样，支持交换两色。
- 前景半透明时先与背景合成；背景半透明时要求指定底色，再合成后计算。
- 按 WCAG 2.2 / sRGB 相对亮度和对比度公式计算，**判定使用未舍入值**，显示保留两位小数。
- 检查项：
  - 普通文字：AA ≥ 4.5、AAA ≥ 7
  - 大文字（≥18pt 常规或 ≥14pt 粗体）：AA ≥ 3、AAA ≥ 4.5
  - 界面组件与图形（相邻颜色）：≥ 3
- 状态同时使用图标和「通过/未通过」文字，不只依赖红绿颜色。
- 实时预览中文正文、英文正文、大字号标题和按钮，文案可编辑。
- 提示抗锯齿边缘可能混合前后景色，应选择笔画实色和纯色背景。

已用标准样例验证：黑白 21.00、同色 1.00、白底 `#767676` 为 4.54（通过 AA）、`#777777` 为 4.48（未通过）、`#767776` 显示 4.50 但按未舍入值 4.496 判定未通过；半透明红 50% 与白底合成后实际背景为 `#FF8080`。

## 二维码与条码

### 生成
| 类型 | 校验与行为 |
| --- | --- |
| 网址二维码 | 必须是有效的 `http://` 或 `https://` 地址 |
| 纯文字二维码 | 保留空格与换行；超出编码容量时提示缩短 |
| Wi-Fi 二维码 | SSID、WPA/WEP/开放网络、密码、隐藏网络；特殊字符 `\;,:"` 按 Wi-Fi 格式转义；密码默认遮盖，但二维码和导出包含实际连接信息 |
| Code 128 | 仅允许 ASCII 字母、数字和常用符号；可显示/隐藏下方编号 |
| EAN-13 | 12 位数字自动补校验位；13 位数字验证校验位；保留前导零，错误时说明原因 |

- 实时预览；默认深色码、白色底并保留四周留白。
- 支持下载 PNG 和 SVG；PNG 由固定画布整数像素渲染，不做模糊缩放；SVG 由 `qrcode` / `JsBarcode` 生成，用户输入按文本处理，不直接拼接可执行标记。
- 显示「编码内容」；Wi-Fi 内容中的密码显示为 `***`，实际二维码内容可通过识别或扫码核对。

### 识别
- 支持拖入、选择、粘贴图片，本地识别 **QR Code、Code 128、EAN-13**。
- 显示识别格式、原始内容与复制按钮；文本按纯文本显示。
- 检测到网址时显示完整地址，只有用户主动点击才打开，且仅允许 HTTP/HTTPS。
- Wi-Fi 结果显示 SSID、加密方式和隐藏网络状态，密码默认遮盖；可「填入生成」继续编辑。
- 支持反转颜色（白码黑底）的二维码。
- 区分：未识别到码、图片无法读取、非图片文件、检测到但暂不支持的码制。
- 单图最多 2400 万像素；识别为本地 CPU 处理，转换过程不阻塞其他页面导航。

已验证：网址/中文换行文本/Wi-Fi 特殊字符/Code 128/EAN-13 生成后由 Nexus 识别回读；PNG 与 SVG 均可打开；EAN-13 前导零与校验位正确；空输入、过长内容、错误校验位、非 ASCII Code 128、坏图和未检测到码都有明确提示。识别与生成过程中无上传/后端请求。

## 依赖

| 依赖 | 用途 | 许可证 | 打包影响 |

| `qrcode` 1.5.4 | 二维码生成（Canvas / SVG） | MIT | 随 `/codes` 懒加载 |
| `jsbarcode` 3.12.3 | Code 128 / EAN-13 生成 | MIT | 随 `/codes` 懒加载 |

| `heic2any`（已有） | 取色页 HEIC 解码复用 | MIT | 仅 HEIC 时懒加载 |

取色页复用 `src/convert/image.ts` 的本地解码/方向处理；对比度计算为项目内小函数（`src/color/color.ts`），按 W3C 公式实现并用标准样例验证。

## 限制与未完成

- 取色页图片最多 2400 万像素；超大图请先缩小。
- 二维码容量受 `qrcode` 字节容量限制，超出会提示缩短；未做结构化追加/多码合并。
- 识别只覆盖 QR Code、Code 128、EAN-13；其他码制会返回「暂不支持」提示。
- 未实现第二阶段：最近颜色/调色板、整组复制、系统屏幕取色、表格批量生成、打印标签、摄像头扫码、单图多码。
- 未引入摄像头权限，也未做服务端处理；所有内容留在当前设备。
