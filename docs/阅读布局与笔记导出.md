# 阅读布局与笔记导出

便利贴统一使用主题正文颜色，保留背景配色；操作区域 40×40，图标 19px。标题可换行，分类位于日期下方。卡片按 CSS 多列排列，每行可选择自动或 1–8 列，窄屏受最小列宽约束自动减少。卡片保持自然高度，最多预览八行。点击标题或「查看全文」打开滚动弹窗，编辑也在弹窗中进行，不会拉长列表。列数保存在当前浏览器。

笔记编辑和预览使用 Element Plus Splitter，支持鼠标拖动以及焦点上的左右方向键、Home、End，比例保存在当前浏览器。笔记右上角「导出」支持当前编辑内容，无需先保存：

- HTML：独立 UTF-8 网页，图片嵌入为 data URL，可以离线查看。
- PDF：使用 html-to-image 与 jsPDF 按阅读效果生成分页文档，尽量避开文字行、表格行和普通图片的中间分页。PDF 当前为图像页面，文字不可搜索复制。
- PNG：保留排版，超长内容超过 6000 CSS 像素会自动分张下载。
- Word：docx 生成真实 .docx，保留标题、段落、粗斜体、列表、表格、链接和图片。复杂 HTML 布局与 CSS 不保证与网页完全一致。

导出依赖动态加载，不占首屏包。图片读取失败会明确报错，不会静默丢图；跨站图片需原站允许跨域读取。

翻译页移除服务选择与重复设置抽屉。默认服务和字号在「设置 → 翻译服务」中统一管理。首选服务不可用时使用已启用且已配置的服务。原文和译文分别按字数计算：默认 100 字以内 28px、101–500 字 21px、超过 500 字 16px，均可调整，关闭自动字号时统一使用长文本字号。偏好保存在当前浏览器。

验证：`npm run build`；`node e2e/reading-workspace.mjs`（本地项目需已启动，并使用 server/.env 的本地登录配置）。浏览器测试覆盖长便利贴弹窗、分类位置、列数持久化、移动端、笔记拖动、含图片的四种文件下载、翻译界面与字号变化。模拟内容通过请求拦截提供，不写入业务库。
