# 工作台可靠性与性能改进

## 新入口

- 顶部「搜索」：跨待办、笔记、便利贴、书签、表格与记录搜索；每类全部搜索最多展示 20 条，不先执行全量计数；选择类型后计算完整数量并可翻页。点击结果定位内容。非编辑状态支持 Ctrl/Command+K。
- 顶部「任务中心」：后台导入、导出、备份与校验，查看进度、取消和重试。徽标显示执行中/排队、近七天失败和 Agent 待审核数量。
- 「操作记录」：从任务中心切换，记录本次升级后的成功写操作。只保存操作人、方法、路径、时间和响应状态，不保存请求正文或令牌。
- 设置 → 系统与备份：自动/手动完整备份、下载和校验。恢复参见「备份与恢复.md」。
- 设置 → Agent 接入：中文字段差异、筛选、审核备注；无结果引用、无文件或外部副作用的独立批次可拆分暂存。拆分仍不会写正式数据，涉及相同模块时后续暂存可能需要重新预览。
- 待办与清单删除加入 30 天回收站，恢复包括父子关系、说明和截止时间。恢复后的 ID 可能改变，以响应中的目标链接为准。

## 性能与契约

笔记、便利贴、待办页面默认每页 50 项，后端支持 1–100 项；待办按顶层任务分页并附带其子任务。为兼容既有客户端，不传 page 的旧 API 仍维持原返回结构。数据很多的 Agent 应主动传 page/page_size，而不是读取旧的全量响应。

Agent 预览/刷新/合并释放外层数据库连接，内部业务操作借用同一个事务；指纹计算转到线程执行。表格单记录修改检查本记录及表结构，不再扫描其他表的全部记录。表级批量操作和其他模块仍采用保守冲突检查，不提供强制覆盖。

看板缓存按用户、看板版本、源表记录数量/更新时间/版本汇总和字段定义失效，最多 64 项、TTL 60 秒。计算列和跨表依赖跳过缓存，避免错误命中。普通 PostgreSQL 指标卡使用 NUMERIC 聚合；日期筛选、分组和计算列继续走原有校验与计算路径。

大组件保留按需加载，增加加载/错误反馈。构建一次生成 Brotli/Gzip 静态产物，FastAPI 按 Accept-Encoding 返回对应内容，Nginx 使用 gzip_static。内容哈希资源长期缓存，HTML 不缓存；工作簿仍是较大依赖，并未为了减小文件而删除功能。

导出和导入确认在持久任务队列中执行。导入预览仍在上传后生成；确认前编辑映射会使原排队任务失效，防止导入未核对的映射。导入写入仍保持整批数据库事务，失败或提交前取消时回滚；不承诺断点续传或外部副作用回滚。

新增迁移 f2a3b4c5d6e7：任务、操作记录、审核备注与列表索引。旧 create_all 部署已存在的 memo_categories/agent_changes 在对应迁移中先检查结构，再接入版本管理。

验证：后端全量回归、PostgreSQL 专项、1 万行后台导出、加密恢复演练、单连接 Agent 预览/刷新/合并及浏览器端分页、搜索定位、任务、备份、回收站、中文审核和成熟组件回归。
## 本轮实测（WSL 本机）

保留原有 50,000 条表格记录、1,800 条待办、120 篇笔记、124 张便利贴。单次本机接口测量：看板冷读约 283 ms，版本校验后缓存读取约 11 ms；单记录 Agent 指纹检查约 6 ms（此前模块全量扫描约 578 ms，检查范围已收窄）。笔记分页响应约 24.8 KB，便利贴分页响应约 54.3 KB。

工作簿 JavaScript 原文件 7,577,243 字节，Brotli 传输约 1,689,816 字节，内容哈希资源使用长期缓存。依赖本身体积仍大；这项改进减少传输和重复下载，并未把解析和初始化成本降到零。

24 个并发 Agent 暂存请求均返回 202，隔离数据库正式便利贴数量未改变。加密备份恢复到独立 PostgreSQL 数据库后，业务数量一致，旧版本数据库可迁移到 f2a3b4c5d6e7。恢复演练完成后清理隔离副本。

验证记录位于本机 .run/improve-*.log/json：269 项后端测试通过，PostgreSQL 专项 61 项通过、1 项 SQLite 恢复用例按环境跳过；另有独立 PostgreSQL 恢复演练、1 万行后台导出及浏览器流程验证。

Docker 配置已同步，本机无 Docker，未构建镜像。容器固定使用 Python slim-trixie 和 PostgreSQL 17 客户端，避免基础镜像漂移导致备份工具低于 Compose 数据库版本。包与基础镜像信息参考 [Debian 官方包](https://packages.debian.org/trixie/postgresql-client-17) 和 [Python 官方镜像定义](https://github.com/docker-library/python/blob/master/3.12/slim-trixie/Dockerfile)。
