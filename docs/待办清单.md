## 三、P1（下一轮建议做）

- [ ] **到期清理由外部触发**：现在只有 `POST /api/v1/trash/purge-expired`。
      建议在 API 里加一个每小时执行的后台任务（同时清理超过 24 小时且无引用的暂存文件）。
- [ ] **PDF 阅读器**：若需要分页/缩放/适宽，需要引入 `pdfjs-dist` 并把 worker、字体打包进本地资源；
      当前依赖浏览器原生阅读器，功能可用但不可控。
- [ ] **侧栏大量数据表**：造 120 张表验证搜索、滚动与加载耗时；必要时改为虚拟滚动。
- [ ] **1024×768 横屏回归**：目前只测了 1440×900、1280×800、768×1024。
- [ ] **真机平板**：触控命中区、软键盘顶起保存按钮、抽屉手势，需要 iPad 实机截图。
- [ ] **Excel 数字补零格式**：`number_format` 为 `00000` 的单元格目前读成 `123`，
      要按格式还原成 `00123`（需读取 `cell.number_format` 判断）。
- [ ] **笔记粘贴图片**：自动化未覆盖（无头浏览器剪贴板限制），建议在真机 Chrome 上验证一次并留证据。

## 五、已知限制（不是缺陷，是当前取舍）

| 限制 | 原因 | 影响 |
| --- | --- | --- |
| Excel 不支持 `.xls`、CSV 导入 | PRD 9.1 明确范围 | 旧文件需先另存为 `.xlsx` |
| 表格不支持单元格内直接编辑、公式、关联表 | PRD 1.4 范围外 | 编辑走表单 |
| 待办、打卡对象不进回收站 | PRD 6.5 / 13.1 | 删除即不可恢复，界面已有明确提示 |
| 翻译历史无删除入口 | PRD 12.6 | 只读；维护接口保留在 API 内但不暴露 |
| 笔记不支持多级文件夹、普通文档附件 | PRD 1.4 | 单层文件夹 + 图片 |
| 便签无历史版本、无多标签 | PRD 11 | 单分类 + 六色 |
| 打卡实例的历史版本不做完整快照链 | 当前用「实例快照 + 事项修改记录」组合 | 能看到每次修改记录，但无法像数据库那样逐版本回放整份清单 |
