## 运行脚本

在 WSL 的项目根目录 `/home/weiwen/workbench_element` 执行：

```bash
# 查询本批数据
server/.venv/bin/python scripts/seed_mock_data.py status --as-of 2026-11-03

# 生成本批数据；同批次重复执行会检测并跳过，不会追加重复数据
server/.venv/bin/python scripts/seed_mock_data.py seed --rows-per-table 10000 --as-of 2026-11-03

# 在独立 SQLite 中预演，不写业务库
server/.venv/bin/python scripts/seed_mock_data.py seed --preview --rows-per-table 120 --as-of 2026-11-03
```

`--rows-per-table` 指每张表的行数；默认 10000，允许 1–100000。当前增强表格／透视接口的 10000 行边界不因生成脚本而改变。其他模块的示例数量固定，不随该参数变化。

默认批次来自 `--as-of` 日期。需要另加一套数据时，可传不同 `--batch`（1–24 位字母、数字、下划线或连字符）；这会新增一套数据，原批次保留。

- 普通模式仅允许当前配置连接到本机 `workbench_element_local`；预演模式使用 `.run/mock-preview/<批次>/preview.sqlite3`。
