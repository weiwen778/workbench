# 表格增强（本地版）

2026-10-31。保留原表、记录、附件、Agent 接口和数据可视化；默认进入增强视图，右上角「经典视图 / 导入导出」可以切回原界面。

## 可以怎样使用

| 入口 | 功能 |

## 关联与计算

新增「关联记录」「整列公式」「关联查找」「关联汇总」字段。关联可以选择单条或多条记录，查找读取关联记录的指定列，汇总支持计数/合计/均值/最小/最大。计算字段只读，原字段变更后按当前数据重新计算；经典读取、导出和数据可视化使用同一计算结果。计算错误显示在对应单元格，不会覆盖原记录。

整列公式示例：`ROUND({数量} * {单价}, 2)`。列名在保存时绑定到稳定字段键，重命名不会破坏已保存的表达式。支持基本算术、比较，以及 IF、SUM、AVG、MIN、MAX、COUNT、ROUND、ABS、LEN、CONCAT、COALESCE、DATE_DIFF。表达式通过受限 AST 解释，不执行 Python。循环依赖、超大表达式和不受支持的函数会被拒绝。

网格中的「整列公式」属于数据表字段。电子表格中的 `=SUM(A1:A10)` 属于 Univer 单元格公式，二者各自计算。

## 保存与冲突

网格批次整体校验、整体提交；请求编号支持幂等重试。保存失败保留本次编辑，允许重试或明确放弃。离开视图前会等待保存；有冲突时阻止离开。撤销/重做检查记录版本和表结构版本，不覆盖后续修改。列结构改变前的历史仍可查看，但不能跨结构变更撤销。原有导入任务不进入本次逐行撤销历史。

历史按账号保存，Agent 写入计入令牌拥有者并注明来源。被替换附件保留到相关记录永久清理，以支持撤销。历史不提供实时多人同步或完整审计合规能力。

电子表格首次打开复制原表当前快照，随后独立保存到本账号；编辑不会写回原表，也不会随原表自动变化。「复制原表快照」可明确重新覆盖工作簿。工作簿自动保存，失败时保留内存并尽力保存到本机 IndexedDB；刷新后可选择恢复。浏览器清理网站数据会清除本机备份，重要内容可导出备份。

## 文件互通与边界

- 工作簿支持 JSON 完整快照备份、首张工作表 CSV、常见 `.xlsx` 导入导出。保留内容、公式、合并、冻结及常用字体、底色、数字格式；不承诺复杂 Excel 格式无损，宏、图表、图片对象和外部连接不导入。其他格式请先另存为 `.xlsx`。
- 增强视图当前最多 10000 条有效记录；超过时明确提示，仍可用经典视图分页。计算列筛选/排序、含计算列的统计和导出同样受 10000 行约束。
- 单次批量编辑最多 500 行、5000 个字段值；粘贴须落在已存在的行列内。计算列不可覆盖。选区操作支持连续矩形区域。
- 工作簿最多 30 张表、100000 个非空单元格、JSON 10MB；每张表最多 100000 行、1000 列。CSV 矩形范围最多 100 万格。透视展示最多 50 个列维度值、1000 个分组，超出明确提示。
- 大数值字段保持十进制字符串；复制到工作簿时超过 15 位有效数字的数值以文本保留。工作簿数值计算仍遵循电子表格引擎的数值规则。

## 依赖与加载

Vue 页面使用 VTable 1.26.8（MIT）作为数据网格，Univer 1.3.0 开源预设（Apache-2.0）作为独立工作簿，decimal.js 10.6.0（MIT）处理十进制汇总。Grist、Glide Data Grid 的交互思路用于设计，未直接引入其整套应用或 React 网格。未使用 Univer 商业协同/服务端导入导出功能；常见 XLSX 互通由受大小限制的 openpyxl 适配完成。

两个引擎均按需加载。当前主入口约 342KB（gzip 119KB），VTable 主块约 2.15MB（gzip 535KB），工作簿主块约 7.47MB（gzip 1.98MB）。普通打卡/笔记页面不下载这两个引擎；首次打开表格和工作簿会增加下载及初始化耗时。构建仍保留大块警告，后续可以继续做更细的拆包。

## 复测

后端测试默认使用独立临时 SQLite，PostgreSQL 测试仅允许本机 `workbench_element_test*` 数据库：

```bash
cd server
.venv/bin/pytest -o addopts=
# WB_TEST_DATABASE_URL=postgresql+psycopg://...@127.0.0.1/workbench_element_test... .venv/bin/pytest -o addopts=
cd ../web
npm ci
npm run build
```

浏览器测试准备新建的隔离数据库和 1000 条测试记录，不连接本地正式库：

```bash
# 从仓库根目录启动；测试端口被占用时会拒绝启动
server/.venv/bin/python e2e/table-fixture.py
cd e2e
npm ci
WB_BASE=http://127.0.0.1:18747 node table-core.mjs
WB_BASE=http://127.0.0.1:18747 node table-workspace.mjs
WB_BASE=http://127.0.0.1:18747 node table-workbook-recovery.mjs
```

测试进程 PID、数据库路径和日志在 `.run/table-upgrade-test/`。停止时先核对 `/proc/<PID>/cmdline` 是该目录下的 `serve-table-upgrade.py`，再只终止该 PID。不要对正式库运行浏览器写入测试。浏览器默认 Chromium；Windows 可通过 CHROME_PATH 指定 Chrome。
