侧边栏右边界支持左右拖动，默认 192px，最小 180px，最大 360px；窗口较小时还限制在窗口宽度的 28% 以内，并为内容区域保留至少 640px。桌面模式下生效，窄于 1280px 时沿用原有手机/平板导航抽屉。

宽度保存在本机 localStorage，刷新、切换页面、折叠再展开后恢复。窗口缩小时临时收紧显示宽度，回到大屏后恢复偏好。双击边界恢复默认；拖动过程中按 Escape 取消。边界支持 Tab 聚焦，左右方向键每次调整 10px，Shift+方向键调整 20px，Home/End 到最小/最大。
