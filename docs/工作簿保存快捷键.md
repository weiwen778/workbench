# 工作簿保存快捷键

自由工作簿激活时支持 Ctrl+S / Command+S，不触发浏览器保存网页。保存前通过编辑器Facade结束并提交当前单元格编辑，再保存快照；菜单立即保存、失败重试和模式切换的保存检查也走相同逻辑。

保留编辑器原生快捷键。窗口监听仅在工作簿组件挂载期间存在，原始表或其他模块不拦截；有对话框、输入法组合输入或额外Alt/Shift修饰键时不处理。连续保存合并进行，失败保留草稿和重试入口。初始化失败但不存在草稿时仍允许离开。

隔离浏览器回归验证：未按Enter的单元格使用Ctrl+S提交并持久化、原生Ctrl+Z/Y、Command+S、失败后热键重试、默认浏览器行为被阻止、离开后不拦截、原始记录保持不变。仅WSL本地。
