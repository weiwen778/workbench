# 格式转换

> 纯前端转换页，路由 `/convert`，侧栏「格式转换」。所有文件只在当前浏览器内处理，不上传服务器。

## 已支持的转换

### 图片

| 输入 | 输出 | 说明 |
| --- | --- | --- |
| JPG / PNG / WebP | JPG / PNG / WebP | 按 EXIF 方向信息自动转正 |
| HEIC / HEIF | JPG | 浏览器端 `heic2any` 解码，失败时给出提示 |

- 尺寸：保持原尺寸，或设置「最长边」等比缩放（不会放大原图）。
- 画质：JPG / WebP 可调（10–100）。
- 透明图转 JPG：可选底色，默认白色。
- 透明图转 PNG / WebP 保留透明通道。

### PDF

| 转换 | 设置 |
| --- | --- |
| 多张图片合成 PDF | 拖动调整页序；页面「按图片大小」或「A4」；A4 可设页边距；输出文件名 |
| PDF 指定页 → PNG / JPG | 页码范围（如 `1,3-5`，留空为全部）；清晰度 1x/1.5x/2x/3x；JPG 画质；输出文件名带页码 |

- 合成时间距按比例适配，不拉伸图片；透明图在 PDF 中以白色底合成。
- 无效或越界页码在打开设置时就提示，并禁用保存。
- 加密 PDF 会提示「PDF 已加密，暂不支持转换」。
- 多页图片输出打包为 ZIP，文件名形如 `文档-第3页.png`。

### 表格

| 转换 | 设置 |
| --- | --- |
| CSV → XLSX | 分隔符（自动 / 逗号 / 分号 / Tab / 竖线）；编码（UTF-8 / GBK / GB18030 / UTF-16LE / Big5）；首行是否为表头；工作表名称 |
| XLSX → CSV | 单个工作表或全部工作表分别导出（多个打包为 ZIP） |

- CSV 预览显示前 6 行，可提前发现乱码、分隔符错误和前导零丢失。
- 前导零按文本保存（如 `00123` 不会变成数字 123）。
- CSV 导出使用 UTF-8 BOM，兼容 Excel 中文；公式字符开头的文本自动加 `'` 前缀，避免被 Excel 当公式执行；负数等纯数字保持不变。
- XLSX 公式导出**已有计算值**；缺少缓存值时给出逐项警告，并在 CSV 中留空。
- CSV 只保存数据；公式不会写入 CSV。

## 通用能力

- 混合导入：拖拽、文件选择、`Ctrl/Cmd + V` 粘贴剪贴板文件。
- 常用入口：HEIC 转 JPG、图片合成 PDF、PDF 转图片、CSV 转 Excel；入口会自动套用目标格式。
- 队列：文件名、大小、源格式、目标格式、逐项参数、状态、真实进度（分页/多文件时按进度更新）。
- 同类批量：设置弹窗里的「应用到其他同类」；单项仍可单独修改。
- 转换：单项/全部转换；失败项逐项重试；等待/转换中可取消（取消后其他项继续）。
- 结果：图片缩略图、PDF 首页、表格前几行；单项下载、按分类打包、全部成功结果打包；ZIP 内同名文件自动加序号。
- 预设：保存、命名、应用、删除；保存在 `localStorage`（`wb_convert_presets`）。
- 限制：默认单文件图片 50 MB、PDF 100 MB、表格 30 MB、队列 50 项、并发 2、单项超时 30 分钟；页面右上角「转换限制」可修改（`wb_convert_limits`）。

## 运行位置与依赖

全部转换在浏览器内完成，**没有后端转换接口，也不会上传文件**。

| 依赖 | 用途 | 许可证 | 打包影响 |
| --- | --- | --- | --- |
| `pdfjs-dist`（已有） | PDF 渲染/页数/首页预览 | Apache-2.0 | 按需加载 |
| `jspdf`（已有） | 图片合成 PDF | MIT | 按需加载 |
| `fflate`（已有） | ZIP 打包 | MIT | 按需加载 |
| `xlsx@0.18.5` | XLSX 读写、公式缓存值 | Apache-2.0 | 随转换页懒加载，约 509 KB（gzip 171 KB） |
| `papaparse` | CSV 解析（引号、换行、分隔符） | MIT | 随转换页加载 |
| `heic2any@0.0.4` | HEIC/HEIF 解码（libheif wasm） | MIT | 仅 import HEIC 时懒加载，约 1.35 MB（gzip 341 KB） |

构建：`cd web-react && npm run build`。转换页按路由懒加载，不影响其他页面首屏。

## 未纳入本期

按「纯前端、只在界面展示已接通能力」的约束，以下暂不提供入口：

- **音视频**：MOV → MP4、提取 MP3。浏览器端没有可靠、轻量的通用转码引擎；`ffmpeg.wasm` 体积大、性能受限，本期不引入。界面不展示相关入口。
- 第二阶段：AVIF/SVG/GIF、Office → PDF、OCR、PDF → Word、CSV ↔ JSON、TSV → XLSX、音频格式互转、MKV/WebM、视频 GIF/封面、字幕/文本转换。
- 加密 PDF、超大文件（受浏览器内存限制）、损坏文件只会逐项报错，不影响其他任务。

## 验证记录

使用真实样本在浏览器中验证：

- 透明 PNG → JPG 指定红色底：输出 400×300，角落为红色。
- 带 EXIF 方向 6 的 JPG → PNG：输出 300×400（方向已转正）。
- HEIC → JPG：解码成功，缩略图与输出均可显示。
- WebP → JPG、最长边 200：输出 200×150。
- 三/多张图片合成 PDF：拖动调整页序后，转回图片检查页序正确；A4 输出宽高比 1.414。
- 5 页 PDF 指定 `1,3-5` → 4 张 PNG，文件名带页码；页码 `9` 在设置阶段提示越界。
- CSV（中文、逗号、嵌换行、`00123`）→ XLSX：数据与前导零正确；GBK 编码切换后正常。
- CSV 公式字符文本 → XLSX：全部按字符串保存；XLSX → CSV 自动加 `'` 前缀。
- XLSX 两个工作表 → CSV：ZIP 内两个文件；缺少计算值的公式有警告并导出为空。
- 转换过程中网络面板无上传/后端转换请求。
- 深色主题、手机宽度（390px）布局正常。

测试截图和下载产物位于忽略目录 `.run/`。
