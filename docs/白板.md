# 白板

工作台的第一阶段白板模块：侧栏入口、白板列表、Excalidraw 编辑器、本地草稿、服务端保存、图片资源、模块插入与导出。多人实时协作和评论不在本阶段范围内。

## 入口

| 位置 | 行为 |
| --- | --- |
| 侧栏「白板」 | `/whiteboards` 白板列表 |
| 白板列表「新建白板」 | 输入名称后创建并进入编辑器 |
| 便利贴卡片「添加到白板」 | 选择已有白板或新建，把便利贴内容副本插入 |
| 便利贴详情「添加到白板」 | 同上 |
| 图片处理顶部「发送到白板」 | 把已勾选图片（未勾选时用当前图片）的处理结果插入目标白板 |

白板编辑器路由为 `/whiteboards/:boardId`，按路由懒加载；Excalidraw 的字体与编辑器代码只在该路由加载。

## 页面与交互

### 白板列表

- 按最近编辑时间倒序，显示元素数量、更新时间；有未保存本地草稿的白板显示「本地草稿」标记。
- 支持新建、搜索、刷新、重命名、复制、删除。
- 删除使用现有确认对话框；复制由服务端复制场景，复制后两个白板独立编辑，共用图片资源。
- 入口沿用工作台现有浅色/深色主题、MUI 卡片和中文提示。

### 编辑器

- 顶部：返回列表、可编辑标题、保存状态、保存按钮、导出菜单。
- 画布占满剩余空间，使用 `session.theme` 跟随工作台浅色/深色主题。
- Excalidraw 语言为 `zh-CN`，工具栏、菜单和快捷键提示为中文。
- 快捷键限制在 Excalidraw 编辑器内；全局 `Ctrl+K` 搜索会忽略 `.excalidraw` 内的按键。
- 原生能力：
  - 自由笔（鼠标、触屏、手写笔）
  - 原生橡皮擦（按当前工具模式整笔或分段擦除）
  - 文字（中文输入法由 Excalidraw 处理）
  - 便签/文本、矩形、椭圆、菱形、直线、箭头
  - 拖动、多选、对齐、删除、撤销/重做、缩放、平移
  - 箭头绑定节点，移动节点时箭头跟随
  - 拖入、选择、`Ctrl / Command + V` 粘贴图片，可在图片上继续圈画
- 图片进入前端后先本地解码，场景引用稳定的 `fileId`；保存前才上传被引用的新图片。

### 导出

「导出」菜单：

- **复制选区为图片**：选中对象后通过 Excalidraw 写入 PNG 剪贴板；浏览器拒绝剪贴板写入时自动下载 `标题-选区.png`。
- **导出整板 PNG**：导出当前所有未删除对象，保留笔迹、图片、箭头和中文。
- 白板为空时提示「白板还没有内容」；有内容但未选择对象时提示先选择。

## 前端草稿

`src/whiteboard/db.ts`：

- IndexedDB 数据库 `nexus-whiteboard`，对象仓库 `drafts`。
- 键为 `wb-draft-v1:{userId}:{boardId}`，按账号和白板隔离。
- 草稿记录包含：
  - `elements`：Excalidraw 可编辑场景（含删除标记，保证撤销恢复）
  - `appState`：恢复所需的视图与默认样式白名单（背景、网格、缩放、滚动、当前描边/字体等）
  - `files`：被引用的本地图片 dataURL
  - `baseVersion`：草稿基于的服务端版本
  - `dirty`、`updatedAt`
- 内容变化后约 500 ms 合并写入；页面隐藏、刷新、离开编辑器时再次写入。
- 写入失败（配额不足、存储不可用）时保留内存状态，顶部显示警告并提示保存或导出。
- 不把选择状态、悬停、协作者等界面状态写入草稿。

保存策略：

- 内容变化（元素版本/版本号变化）才标记为未保存；仅缩放、平移、悬停不触发服务端保存。
- 自动保存：停止编辑约 2 秒后触发；指针按下期间自动延后，避免笔画中发请求。
- 手动保存立即执行，与自动保存共用串行队列。
- 状态：`有未保存更改`、`保存中`、`已保存`、`待同步`、`版本冲突`。
- 保存请求串行；保存期间的新编辑保留为待保存。旧响应只有在编辑序号未变化时才清除未保存状态，不会把新内容误标为已同步。
- 网络失败/超时：保留草稿，显示「待同步」，按 2s、4s…最长 30s 退避重试，也可手动重试。
- 版本冲突：保留本地草稿并展示冲突条，可选择：
  - **另存为副本**：先上传新图片，创建新白板并保存当前本地场景，然后进入副本。
  - **载入服务器版本**：二次确认后丢弃当前白板本地草稿并重新载入服务器内容。
- 打开白板时：若有未同步草稿且 `baseVersion` 等于服务器版本，恢复草稿并标记待保存；若服务器版本已前进，恢复草稿但进入冲突状态，不自动覆盖服务器内容。

## 服务端

新增表（迁移 `20261114_c5d6e7f8a9b0_whiteboards.py`）：

- `whiteboards`：`id`、`user_id`、`title`、`scene`(JSON)、`version`、`created_at`、`updated_at`
- `whiteboard_assets`：复合主键 `(user_id, id)`、`storage_key`、`content_type`、`size`、`created_at`

图片资源按 `(账号, Excalidraw fileId)` 归属。Excalidraw 的 `fileId` 是内容哈希，不同账号可能粘贴同一张截图；复合主键避免跨账号 ID 冲突，同时保持场景引用不变。

接口（均需登录，并校验白板/图片归属）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/whiteboards` | 列表，按最近编辑排序，不含场景 |
| POST | `/api/v1/whiteboards` | 新建 |
| GET | `/api/v1/whiteboards/{id}` | 读取场景 |
| PUT | `/api/v1/whiteboards/{id}` | 保存 `elements`、`app_state`、`version`；版本不匹配返回 409 |
| PATCH | `/api/v1/whiteboards/{id}` | 重命名 |
| POST | `/api/v1/whiteboards/{id}/duplicate` | 复制，返回新白板 |
| DELETE | `/api/v1/whiteboards/{id}` | 删除白板；图片资源保留 |
| POST | `/api/v1/whiteboards/assets` | 以 `file_id` + `file` 幂等上传图片 |
| GET | `/api/v1/whiteboards/assets/{file_id}/content` | 读取当前账号的图片内容 |

一致性：

- 保存顺序：先上传场景中新增且被引用的图片，再提交引用这些 `fileId` 的场景。
- 资源上传幂等；同一账号重复上传同一 `fileId` 返回已有资源。场景保存失败后重试复用已上传资源。
- 仅修改笔迹/文字时不会重新上传已保存图片（浏览器测试中第二次保存上传次数不变）。
- 场景保存时校验图片归属；引用未上传图片返回 422。
- 场景最大 20 MB；图片沿用项目单文件上传上限。
- 删除白板不删除图片行，因此仍被其他白板引用的图片可继续读取；维护任务会扫描所有白板场景，超过 24 小时且没有引用的图片资源才删除，给本地未保存草稿留出恢复窗口。
- 复制白板共享图片资源；复制后独立编辑，删除源板不影响副本图片。

## 已知限制与未验证项

- 未实现多人实时协作、评论、版本历史。
- 原生橡皮擦的具体模式（对象/分段）由 Excalidraw 工具栏决定；已验证分段擦除与撤销/重做。
- 无法验证真实手写笔压感和不同触控设备；已用 Chromium CDP 触控事件验证单指绘制和双指缩放，压感需真机手工验收。
- 中文输入法组合输入未做自动化 IME 验证；已用直接中文输入验证字体和保存，建议人工用系统输入法再验一次。
- 离线保证面向「编辑器已加载」：断网后可继续编辑、写草稿、导出；冷启动仍依赖 Nexus 现有应用壳缓存能力。
- 图片资源按引用扫描延迟回收：默认超过 24 小时且无任何白板场景引用时删除；共享副本引用的资源不会被误删。
- 草稿配额不足时只警告，不自动清理其他草稿；需用户保存或导出后自行处理。
- 场景上限 20 MB、图片沿用项目上传限制；超大素材需先压缩。
- Excalidraw 0.18.1 自带素材库、激光笔、框架等能力；本阶段未将其纳入产品说明，也未接入协作功能。
- 编辑器 chunk 超过 Vite 默认 500 KB 警告线，已通过路由懒加载隔离，不影响其他页面首屏。
