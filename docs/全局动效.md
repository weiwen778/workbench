# 全局动效

采用轻量的 Notion 风格，常用时长 120～180ms。规则集中在 `web/src/styles/motion.css`，仅使用现有 Vue / CSS 能力，没有新增运行依赖或后端接口。

- **侧栏**：六个分组使用自适应高度过渡，箭头同步转动；同时只允许一个分组展开，刷新全部收起。收起内容设置 inert 和 aria-hidden，键盘不会进入隐藏子项。桌面、图标栏弹出菜单和手机抽屉一致。
- **页面**：切换路径时内容淡入并上移 4px，侧栏与顶栏保持稳定；不等待退场动画，不给表格行、输入过程或图片画布增加持续动效。
- **弹窗与菜单**：弹窗轻微淡入缩放，关闭更快；保留组件原有焦点、Escape 和遮罩行为。Popper 外层只改透明度，避免覆盖定位用的 transform。
- **按钮**：悬停颜色柔和过渡，按下轻移 1px，禁用及加载中的按钮不做按压动作。
- **待办**：服务端确认完成后显示划线反馈，约 180ms 后移入已完成区，其余行平滑收拢。防止重复提交；子任务同样支持。失败恢复原有勾选状态及键盘焦点，离开页面清除等待计时器；取消完成可返回待办区。

系统开启「减少动态效果」后，装饰性移动、缩放、过渡和完成停顿关闭，操作即时生效；进度指示器保留。无额外设置开关。

验证：TypeScript / Vite 构建通过；`e2e/global-motion.mjs` 使用隔离服务验证手风琴中间高度、单分组、弹窗取消、保存失败、重复操作、父子任务、快速离开、减少动态效果、移动端与图标弹出菜单。既有分类导航与发布验收覆盖笔记保存保护、表格、PDF 与图片工具。
