# 全局动效

> 现行规范（2026-11-15）。取代此前 Vue 版实现留下的两条限制：「不等待退场动画」「不给表格行、输入过程、图片画布增加持续动效」。设计文档见 `docs/superpowers/specs/2026-11-15-motion-system-design.md`。

## 一句话

一套 tokens，按「组件类型」分配动作，不按页面写动画。全站手势一致，每个组件有自己的动作。

## 在哪

- 代码：`web-react/src/motion/`
  - `tokens.ts` 时长、曲线、弹簧、位移
  - `presets.ts` 变体集合
  - `useMotionSafe.ts` 系统「减少动态效果」判定
  - `components/` 各类原语
- 样式：`web-react/src/styles/layout.css` 的「动效」段（`wb-pop-in`、`wb-breathe`、`wb-pressable`、`wb-thumb`）

## Tokens

| 项 | 值 | 用途 |
|---|---|---|
| `DURATION.fast` | 140ms | 退场、hover |
| `DURATION.base` | 180ms | 入场默认 |
| `DURATION.slow` | 240ms | 图表、抽屉内容 |
| `DURATION.slower` | 320ms | 大块内容 |
| `EASE_OUT` | `[0.22, 1, 0.36, 1]` | 进场 |
| `EASE_IN` | `[0.4, 0, 1, 1]` | 退场 |
| `SPRING.gentle / snappy / bouncy` | — | 抽屉、拖拽重排、勾选 |

退场永远比进场短。

## 分类原语

| 原语 | 应用位置 | 动作 |
|---|---|---|
| `PageTransition` | `AppLayout` 内容区 | **不做动画，即时切换**。旧页面瞬间移除、新页面从透明淡入时，中间露出的是背景色，观感就是「闪一下」；交叉淡入又会叠重影。真正的等待交给 `SkeletonPulse` |
| `StaggerList` / `StaggerItem` | 书签、白板列表、看板卡片 | 逐个 fade + 上移 8px，间隔 20ms，**封顶 12 项**，超出整块淡入 |
| `LiftCard` | 书签、白板、看板、便利贴卡片 | hover 上浮 2px + 边框/阴影过渡，不做 scale |
| `SpringDrawer` | 记录抽屉、字段管理、分类管理、导航抽屉、打卡管理/历史 | Slide 曲线拉长、退场缩短；焦点与 Escape 行为保持 MUI 原生 |
| `PopDialog` | 全站弹窗（含 `layout.css` 的全局规则） | 96%→100% 缩放 + 淡入，关闭走更短的 Fade |
| `ToastStack` | `ui/feedback.tsx` 的 `Toaster` | 顶部滑入，多条 `layout` 自动位移堆叠 |
| `SkeletonPulse` | `LoadingScreen`、`AppLayout` 的 Suspense | 呼吸方块 + 骨架行 + 文案；只在内容真的没到时出现 |
| `CountUp` | 可视化指标卡 | 数值变化时滚动到新值；**首屏不滚**（保护既有断言） |
| `ChartFrame` + `useChartSkipAnimation` | 可视化图表 | 数据到达时淡入上浮；`skipAnimation` 跟随系统偏好 |
| `PopCheckedIcon` | 待办、打卡的勾选框 | 选中图标挂载时轻弹一次 |
| `ProgressRing` / `Burst` | 打卡工具栏 | 完成率环形填充；完成时 3 个点散开 |
| `RowFlow` | 预留 | 真实 `<tr>` 表格的行入场；DataGrid 虚拟滚动表格**不启用** |

## 三个模块的个性

- **打卡**：完成率环形进度 + 完成瞬间粒子 + 勾选弹跳。（打卡是行列表而非卡片，原设计的「目标卡盖章」没有落地对象，改为把重点放在完成反馈上。）
- **可视化**：图表绘制动画、指标滚动、看板卡片上浮、拖拽重排走 220ms 长尾曲线。
- **白板**：缩略图 hover 微倾斜 1°；Excalidraw 工具栏按钮按压缩放 0.94。

## 护栏

1. 所有原语内部走 `useMotionSafe()`；系统开启「减少动态效果」时 `duration: 0`、无位移、无延迟。
2. `layout.css` 的全局 `prefers-reduced-motion` 兜底保留，CSS 动画一并压到 0.01ms。
3. `StaggerList` 封顶 12 项；`RowFlow` 仅 ≤100 行启用。
4. 不动画 `filter: blur`；卡片阴影只在 hover 时过渡。
5. 不新增运行依赖，只用已有的 `framer-motion` 与 MUI。
6. 业务页面只接入原语，不写内联 variants。
