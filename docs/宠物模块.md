# 宠物模块

工作台内的一个轻量虚拟宠物：单用户、单只狗，按真实时间缓慢衰减五项状态，每天花一两分钟照顾就能维持，健康有下限、不会死亡。数据随整库备份一起备份，删除即重来。

## 入口

| 位置 | 行为 |
| --- | --- |
| 侧栏「生活 → 宠物」 | `/pet` 页面，未领养时显示领养卡片，已领养时显示房间、状态面板与动作栏 |

路由 `/pet` 按需懒加载；宠物页在未领养时显示「领养一只狗」卡片，领养后显示狗狗房间、五项状态面板和动作按钮。

## 领养与成长

- 首次进入 `/pet` 时未领养，可给狗狗起名（默认「旺财」，1–12 个字）并领养；每个账号只能领养一只（`pets.user_id` 唯一）。
- 领养后可在工具栏「改名」。
- 按照顾天数进入成长阶段：**幼犬**（< 7 天）→ **成年**（< 30 天）→ **老年**（≥ 30 天）。照顾天数按「当天至少执行过一次照顾动作」的本地自然日累计。

## 五项状态与真实时间衰减

页面展示五项状态：**饱腹、清洁、心情、精力、健康**（0–100，取整显示）。

- 衰减按**真实时间**推进，与页面是否打开无关：每次读取/操作时，后端按 `last_tick_at` 到当前时间的时间差逐步结算，关掉网页也会继续掉。
- 清醒时每小时衰减：饱腹 −1.5、清洁 −0.8、心情 −1.2、精力 −1.5（便便越多、生病时清洁与心情掉得更快）；睡觉时精力每小时 +12，其余衰减减半。
- 健康由长期忽视推导：四项核心状态任一项长期过低（低于 10）会进入「忽视」计时，超过 12 小时宽限后健康每天 −20；核心状态恢复（≥ 40）后健康每天 +8。
- 约 3 天不管会明显变差，约 4 天会生病；健康有下限 **10**，**不会死亡**。生病有滞回：健康 ≤ 60 进入生病，恢复到 ≥ 75 才痊愈。
- 每天照顾 1–2 分钟即可维持状态，属于轻量陪伴，不要求高频操作。

## 状态与便便

- 状态标签：睡觉中 / 生病了 / 饿坏了 / 困得不行 / 脏兮兮 / 不开心 / 精神很好 / 还不错。
- 清醒时约每 8 小时产生一堆便便，最多 3 堆；便便越多，清洁与心情衰减越快。**洗澡会清空所有便便**。

## 动作与冷却

动作按钮：喂食、零食、洗澡、玩耍、遛狗、睡觉/叫醒、看医生、抚摸（点击房间里的狗也可抚摸）。

- 冷却时间由**后端返回**（`cooldowns`，单位为秒），前端只做倒计时展示与禁用，不作判断。
- 各动作冷却：抚摸 5 秒、玩耍 20 分钟、喂食 30 分钟、零食 1 小时、洗澡 2 小时、遛狗 4 小时、看医生 8 小时。
- 部分动作有额外条件：吃饱了不能喂、没有零食不能喂零食、睡觉时只能叫醒、生病时不能玩耍/遛狗、精力不足不能玩耍/遛狗、遛狗仅限本地时间 07:00–22:00、健康 ≥ 85 时无需看医生。
- 抚摸额外限制：同一小时内累计抚摸最多获得 15 点心情（每次 +3），摸满后需等到下一个整点。
- 睡觉可主动开启（精力恢复），也可随时叫醒。

## 每日奖励

- 每天**第一次打开宠物页**时，若当天有已完成打卡或已完成待办，自动发放一次奖励：**心情 +6、零食 +1**，来源为打卡或待办（每天一次）。
- 奖励领取是原子的：并发 GET 也只发放一次。

## 数据与备份

- 宠物数据保存在 `pets` 表（迁移 `20261114_b2c3d4e5f6a7_pets.py`）。
- `pets.user_id` 唯一，对应单用户/单管理员部署，每个账号最多一只宠物。
- `pets` 表随现有整库备份一起备份，删除即重来，无独立备份流程。

## 接口

均需登录（`/api/v1` 前缀）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/pet` | 读取宠物与每日奖励；每次读取会先结算衰减 |
| POST | `/pet` | 领养（可传名字，默认「旺财」） |
| PATCH | `/pet` | 改名 |
| POST | `/pet/actions` | 执行动作（喂食/零食/洗澡/玩耍/遛狗/睡觉/叫醒/看医生/抚摸） |

返回体 `pet` 包含：`name`、`stage`/`stage_label`、`care_days`、`stats`（五项）、`status`/`status_label`、`sleeping`、`poop_count`、`treats`、`cooldowns`（七项冷却）、`next_stage_in_days`、`version`、`updated_at`。动作返回额外 `event` 与 `message`。

## 验证

### 命令

```bash
# 后端全量测试
cd server && .venv/bin/python -m pytest -q

# 宠物单测
cd server && .venv/bin/python -m pytest tests/test_pet.py -v

# 前端类型与构建
cd web-react && npm run typecheck && npm run build

# 浏览器端完整流程（需先启动服务）
cd e2e && WB_BASE=http://127.0.0.1:18080 node pet.mjs
```

e2e 覆盖：领养、改名、刷新后持久化、状态面板、喂食冷却、睡觉/叫醒、抚摸、房间与精灵图、375px 无横向滚动、`prefers-reduced-motion` 下精灵冻结在首帧。
