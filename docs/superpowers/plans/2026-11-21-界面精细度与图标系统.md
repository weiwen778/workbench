# 界面精细度与图标系统 Implementation Plan

> **已回退（2026-11-21）**：深墨绿侧栏 + 衬线标题 + 黄铜方案被用户否决，代码已恢复到上一轮「界面收口」；本计划仅作记录，不要按它继续实现。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改信息架构的前提下，把壳层、字号、表面、图标和三个样板页提升到「精细」的视觉精度。

**Architecture:** 先改主题 token 和图标出口，再改侧栏/顶栏，最后只打磨打卡、表格、便利贴三页。所有图标经 `@/icons` 语义出口；7 个导航图标是自定义 SVG，其余用 Phosphor Regular。现有数据流、路由和业务逻辑不变。

**Tech Stack:** React 18、MUI 6、Emotion、Phosphor Icons、Vite、Playwright。

**Spec:** `docs/superpowers/specs/2026-11-21-界面精细度与图标系统-design.md`

## Global Constraints

- 不加新路由、新功能；不做今日驾驶舱。
- 主色仍是用户可配置的 `themeColor`；黄铜只做侧栏/印章类细节。
- 触屏 `hover: none` 常显操作；键盘 `focus-within` 必须能看见操作。
- 暗色模式、`prefers-reduced-motion`、现有 e2e 必须继续通过。
- 页面标题桌面 24/600、手机 18/600；导航图标 20；工具/行操作 18；行内 16。
- 不提交 git；工作区已有用户改动。

## Review Focus

- 侧栏 232px 宽时，长中文模块名和二级导航不能溢出；窄版 76px 只留图标，Tooltip 必须可读。
- Phosphor 图标经 MUI `sx` 换尺寸时，SVG 不能仍按 24px 渲染；16/18/20 下都要清楚。
- 表格去掉竖线后，列与列之间仍能扫读；固定列阴影不能压住内容。
- 纸色画布 + 墨绿侧栏 + 黄铜选中在暗色模式下不能变成一片黑；对比度要够。
- 操作图标透明但仍在 Tab 顺序；键盘聚焦和触屏常显不能退化。
