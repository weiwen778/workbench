# 界面收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 去掉独立模块横带、建立字号层级、把重复行操作收进 hover/focus，并让手机端打卡筛选可折叠。

**Architecture:** 把 `ModuleTabs` 从整条横带改成 AppBar 内的页面标题下拉；用主题和 `SectionTitle` 统一字号；用 CSS 类控制表格/便利贴操作在桌面端悬停出现；打卡页备注改成图标，手机筛选用本地状态折叠。现有数据流、路由、配色和圆角不变。

**Tech Stack:** React 18、MUI 6、Emotion、Vite、Playwright。

**Spec:** `docs/superpowers/specs/2026-11-21-界面收口-design.md`

## Global Constraints

- 不改主题色 `#14665F`、背景 `#F6F7F6`、圆角 6。
- 不改后端接口、路由和数据结构。
- 触屏设备（`hover: none`）上所有行/卡片操作必须常显，键盘 `focus-within` 必须能显示。
- 现有 `prefers-reduced-motion` 全局规则继续生效。
- 页面标题桌面 19px/600、手机 16px/600；模块面包屑 11.5px。
- 不提交 git，当前工作区已有用户未提交的 `AppLayout.tsx` / `AppRail.tsx` 改动，保留它们。

## Review Focus

- 桌面端标题变成按钮后，长表格/打卡项目名不能撑破 AppBar；窄屏必须省略而不是横向溢出。
- 手机端 390px 宽度下，标题 + 5 个图标 + 折叠按钮必须放得下，不能产生横向滚动。
- 操作图标默认透明但仍在 Tab 顺序里；键盘聚焦必须让它们可见，不能出现「聚焦了但看不见」。
- 触屏上没有 hover，表格和便利贴操作必须常显，不能变成不可发现。
- 打卡备注改成图标后，已有备注仍要能一眼看出（颜色/提示），且点击区域不小于 32px。

```js
// e2e/ui-refinement.mjs
import { chromium } from 'playwright'
import assert from 'node:assert/strict'

const base = process.env.WB_BASE || 'http://127.0.0.1:5174'
const password = process.env.WB_E2E_PASSWORD || 'admin12345'
const browser = await chromium.launch({ headless: true })
const errors = []

async function login(page) {
  await page.goto(`${base}/login`, { waitUntil: 'networkidle' })
  await page.getByLabel('用户名', { exact: true }).fill('admin')
  await page.getByLabel('密码', { exact: true }).fill(password)
  await page.getByRole('button', { name: '登录', exact: true }).click()
  await page.waitForURL(/checkins/, { timeout: 20000 })
  await page.waitForTimeout(500)
}

try {
  const desktop = await browser.newContext({ viewport: { width: 1440, height: 900 } })
  const page = await desktop.newPage()
  page.on('pageerror', (error) => errors.push(error.message))
  await login(page)

  const header = page.locator('header.MuiAppBar-root')
  const headerBox = await header.boundingBox()
  assert.ok(headerBox && headerBox.height <= 60, `AppBar 过高：${headerBox?.height}`)

  const title = page.locator('[data-page-title="true"]').first()
  await title.waitFor({ timeout: 10000 })
  const titleSize = await title.evaluate((el) => parseFloat(getComputedStyle(el).fontSize))
  assert.ok(titleSize >= 18, `页面标题字号不足：${titleSize}`)

  const toolbar = page.locator('[data-module-toolbar="true"]').first()
  const toolbarBox = await toolbar.boundingBox()
  assert.ok(toolbarBox && toolbarBox.y - (headerBox.y + headerBox.height) < 32,
    `标题下仍有独立模块横带：gap=${toolbarBox?.y - (headerBox.y + headerBox.height)}`)

  await page.goto(`${base}/data`, { waitUntil: 'networkidle' })
  await page.locator('.MuiDataGrid-row').first().waitFor({ timeout: 20000 })
  const row = page.locator('.MuiDataGrid-row').first()
  const rowActions = row.locator('.wb-row-actions').first()
  await rowActions.waitFor()
  assert.equal(await rowActions.evaluate((el) => getComputedStyle(el).opacity), '0', '表格行操作默认应隐藏')
  await row.hover()
  await page.waitForTimeout(250)
  assert.equal(await rowActions.evaluate((el) => getComputedStyle(el).opacity), '1', '表格行操作 hover 后应显示')

  await page.goto(`${base}/memos`, { waitUntil: 'networkidle' })
  const card = page.locator('.memo-card').first()
  await card.waitFor({ timeout: 20000 })
  const cardActions = card.locator('.wb-card-actions').first()
  await cardActions.waitFor()
  assert.equal(await cardActions.evaluate((el) => getComputedStyle(el).opacity), '0', '便利贴操作默认应隐藏')
  await card.hover()
  await page.waitForTimeout(250)
  assert.equal(await cardActions.evaluate((el) => getComputedStyle(el).opacity), '1', '便利贴操作 hover 后应显示')

  const mobile = await browser.newContext({ viewport: { width: 390, height: 844 } })
  const phone = await mobile.newPage()
  phone.on('pageerror', (error) => errors.push(error.message))
  await login(phone)
  const filterButton = phone.getByRole('button', { name: /^筛选/ }).first()
  await filterButton.waitFor({ timeout: 10000 })
  await filterButton.click()
  await phone.getByLabel('状态').waitFor({ timeout: 5000 })
  const overflow = await phone.evaluate(() => document.documentElement.scrollWidth - window.innerWidth)
  assert.ok(overflow <= 1, `手机端出现横向溢出：${overflow}px`)

  assert.deepEqual(errors, [], `页面报错：${errors.join(' | ')}`)
  console.log('PASS ui refinement structure, hover actions, mobile filter')
} finally {
  await browser.close()
}
```
