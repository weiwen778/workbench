# 全部功能移入设置 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把侧栏「全部功能」入口收进设置页，让「设置 → 导航」成为完整的全部功能浏览与固定面板。

**Architecture:** 先让 `NavigationSection` 承担原 `ManageNavDialog` 的全部职责（搜索、打开、固定、拖动排序、恢复默认），并删除该对话框；再从 `AppRail` 移除入口，移动端继续用 `NavAllDrawer`。

**Tech Stack:** React 18、MUI 6、react-router-dom 6、@dnd-kit、Playwright e2e。

**Spec:** `docs/superpowers/specs/2026-11-20-全部功能移入设置-design.md`

## Global Constraints

- 固定项按账号保存在 localStorage，必须继续走 `sidebar-order.ts` 的 `readPinnedKeys` / `writePinnedKeys`。
- 不修改 `app-nav.ts` 的模块定义、分组和默认固定项。
- 移动端（`window.innerWidth < 900`）的左汉堡与底部「更多」必须仍能打开 `NavAllDrawer`。
- 界面文案使用中文；可访问名称沿用现有约定：`打开${label}`、`固定${label}`、`取消固定${label}`、`拖动${label}排序`、`搜索功能`。

## Review Focus

- 取消固定全部模块后，面板应显示空状态而不是自动恢复默认项（`readPinnedKeys` 的既有行为）。
- 搜索无结果时应显示「没有匹配的功能」，而不是空白区域。
- 在设置页固定/取消固定后，桌面侧栏应立即变化（`writePinnedKeys` 会派发事件）。
- 移动端从设置目录进入「导航」后，长列表应能随页面滚动，不被固定高度截断。
- 已固定项为空时拖动区域不应报错或产生可聚焦的幽灵按钮。

- [ ] **Step 3: 重写 `NavigationSection`**

保留「侧栏宽度」卡片。新增「全部功能」卡片，结构如下：

- 头部：标题「全部功能」；右侧「恢复默认」按钮；副标题「已固定 {pinned.length} 个，点击模块可打开，图钉可固定到侧栏。」
- `TextField`：`aria-label="搜索功能"`、placeholder `搜索功能`、前置 `Search` 图标，状态 `query`。
- 已固定列表：`DndContext` + `SortableContext`（`items={pinned}`），每行由小组件 `SortablePinnedRow` 渲染：
  - 拖动把手按钮 `aria-label={`拖动${item.label}排序`}`（复用原 `NavPanels.SortablePinnedRow` 的实现）。
  - 整行 `ListItemButton aria-label={`打开${item.label}`}`，点击 `navigate(item.path)`。
  - 行尾按钮 `aria-label={`取消固定${item.label}`}`，文案「取消固定」。
  - 空状态文案「还没有固定项」。
- 其余模块：按 `APP_NAV_GROUPS` 分组，只列未固定且匹配 `query` 的项；分组标题沿用 `group.label`；每行 `ListItemButton aria-label={`打开${item.label}`}` 点击导航，行尾 `IconButton aria-label={`固定${item.label}`}` 放置 `PushPin`。
- 无匹配项时显示「没有匹配的功能」；所有模块都已固定时显示「全部模块都已固定」。

行为函数签名：

```ts
const unpin = (key: string) => void
const pin = (key: string) => void
const onDragEnd = (event: DragEndEvent) => void  // arrayMove 后写入
const reset = () => void                          // 宽度回 narrow，固定项回 DEFAULT_PINNED_KEYS
```

`useSession()` 取 `userId`；状态初始化与同步逻辑沿用现有 `useEffect`；每次变更调用 `writePinnedKeys` / `writeSidebarMode`。
