# 表格渲染性能优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> 执行记录：任务已在工作区完成；为避免混入用户未提交改动，最终未按任务逐步提交，而是随 2026-11-20 整理提交合并。

**Goal:** 消除表格勾选、滚动和双击编辑时的全表重渲染与 emotion 样式重算，在 4 倍 CPU 降速下把点选中位从 153.9ms 降到 90ms 以内，双击打开编辑器从 130.4ms 降到 80ms 以内。

**Architecture:** 保留 MUI DataGrid。DataTable 缓存列定义、用 Map 消除 `rows.indexOf`、支持 DataGrid 内置勾选；TableView 改用内置选择模型，单元格从 MUI `Box + sx` 换成普通 `span + CSS class`，编辑值收进局部组件，避免每次按键重建列。

**Tech Stack:** React 18、TypeScript 5.7、MUI 6、MUI X DataGrid 7、Vite 6、Playwright、Node 24。

**Spec:** `docs/superpowers/specs/2026-11-20-表格渲染性能-design.md`

## Global Constraints

- 不改服务端分页/筛选/排序接口；`page_size` 仅支持 20/50/100。
- 保留现有行为：当前页全选、跨页保留选择、批量删除最多 100 行、左侧固定「日期 + 店铺/门店」、右侧固定操作列、双击单元格编辑。
- 不新增依赖。
- 提交时只暂存本计划涉及的文件，不要 `git add -A`（工作区有大量用户未提交改动）。
- 前端验证命令在 `web-react/` 下执行：`npm run typecheck`、`npm run build`。
- E2E 需要应用运行在 `WB_BASE`（默认 `http://127.0.0.1:18080`）；密码只从环境变量 `WB_E2E_PASSWORD` 读取，不写进仓库。
- 性能基线全部在 4 倍 CPU 降速、41 列、120 行下测量。
- UI 溢出按用户要求「出现具体问题时再处理」：本次只保留单元格省略号和既有 `flexWrap`，不主动重做工具栏/筛选栏布局。

## Review Focus

- **跨页选择**：在第 1 页勾选 2 行，翻到第 2 页再勾选 1 行，批量删除按钮应显示 3 行，且只删除这 3 个 id。
- **当前页全选**：表头复选框只选当前页；已选中的其他页行不能被清掉。
- **编辑提交/取消**：Escape 不保存；Enter 或失焦只保存一次；保存后不能因为 blur 再发一次 PUT。
- **固定列与窄屏**：日期、店铺仍固定在左侧，操作列固定在右侧；单元格长文本省略而不是撑破布局。
- **空表/大表**：0 行和 100 行/200 列时页面不崩、不出现页面级横向滚动。

### Task 2: DataTable 缓存列定义并支持内置勾选

- [x] **Step 2: 建立行索引 Map**

  在 DataTable 内、`gridColumns` 之前：

  ```ts

    const index = new Map<T, number>()

    return index
  }, [rows])
  ```

  把 `getRowId`、`onRowClick`、默认 `renderCell` 中的 `rows.indexOf(...)` 全部替换为 `rowIndexByRow.get(...) ?? 0`。`getRowId` 用 `useCallback` 包裹，依赖 `[rowKey, rowIndexByRow]`。

- [x] **Step 4: 支持内置勾选**

  - `useLayoutEffect` 的守卫改为 `if (!checkboxSelection && pinnedLeft === undefined && !hasActions) return`，注入的 `left` 使用 `pinnedLeftFields`。
  - `pinnedLeftKey` 改为 `[Boolean(checkboxSelection), ...pinnedLeftFields].join('|')`。
  - 给 `DataGrid` 增加：

    ```tsx
    rowSelectionModel={rowSelectionModel}
    ```

- [x] **Step 5: 缓存 DataGrid 的 sx**

### Task 3: TableView 切换内置选择并轻量化单元格

**Files:**
- Modify: `web-react/src/components/TableView.tsx`
- Create: `web-react/src/components/TableCell.tsx`
- Create: `web-react/src/components/table-edit-store.ts`
- Create: `web-react/src/components/TableCellEditor.tsx`
- Modify: `web-react/src/ui/common.tsx`（只加单元格 CSS class）
- Test: `e2e/table-selection-edit.mjs`、`e2e/table-render-performance.mjs`

**Interfaces:**
- Consumes: Task 2 的 `checkboxSelection`、`rowSelectionModel`、`onRowSelectionModelChange`。
- Produces: `TableCellEditor` 默认导出，props 为 `{ field: Field; initialValue: any; disabled: boolean; onSave: (value: any) => void; onCancel: () => void }`；`TableCell` 负责订阅模块级编辑 store。

- [x] **Step 1: 新建局部编辑器组件**

  创建 `web-react/src/components/TableCellEditor.tsx`：

  - `select`：受控 `Select`，`onChange` 立即 `onSave(event.target.value)`，Escape 调用 `onCancel`。
  - `checkbox`：`Checkbox`，`onChange` 立即 `onSave(event.target.checked)`。
  - 其他类型：本地 `useState` 保存输入值；Enter 触发 `blur`；blur 时若未取消则 `onSave(value === '' ? null : value)`；Escape 设置取消标记并 `onCancel`，不得再触发保存。
  - 外层不包 `Box`，TextField 的 `sx` 保持现有编辑器的紧凑样式。

- [x] **Step 2: TableView 改用局部编辑器**

  - 删除 `editValue` 状态和 `skipBlur` ref。
  - 最终实现没有在 `TableView` 里保留 `renderEditor`：`TableCell` 根据模块级 store 决定渲染展示内容还是 `<TableCellEditor field={field} initialValue={...} disabled={...} onSave={...} onCancel={...} />`，编辑状态变化不会重建列定义。
  - `saveCell` 成功时保留 `setEditingCell(null)`。

- [x] **Step 3: 轻量化单元格**

  在 `renderCell` 中：

  - 附件/链接保留现有 MUI `Link`，但去掉外层 `Box`。
  - 勾选列：保留 `Check` 图标；未勾选返回 `<span className="wb-table-cell-text">否</span>`。
  - 其他：返回
    ```tsx
    <span
      className="wb-table-cell-text"
      title={typeof content === 'string' && content ? `${content}（双击编辑）` : '双击编辑'}
      style={['multiselect', 'reference', 'formula', 'lookup', 'rollup', 'attachment'].includes(field.type) ? { cursor: 'default' } : undefined}
      onDoubleClick={(event) => { event.stopPropagation(); startEdit(row, field) }}
    >
      {content}
    </span>
    ```
  - 在 DataTable 的 `sx` 中加入：
    ```ts
    '& .wb-table-cell-text': {
      display: 'block', width: '100%', minWidth: 0, overflow: 'hidden',
      textOverflow: 'ellipsis', whiteSpace: 'nowrap', borderRadius: 4,
      fontVariantNumeric: 'tabular-nums',
    },
    '& .wb-table-cell-text:hover': { backgroundColor: theme.palette.action.hover },
    ```

- [x] **Step 4: 列定义 useMemo 化**

  - 删除自定义 `__select` 列、`allVisibleSelected`、`someVisibleSelected`、`toggleVisibleSelection`。
  - `selection` 改为：
    ```ts
    const [rowSelectionModel, setRowSelectionModel] = useState<readonly (string | number)[]>([])
    const selection = useMemo(
      () => rowSelectionModel.map(Number).filter((id) => Number.isFinite(id)),
      [rowSelectionModel],
    )
    ```
  - 批量删除成功后 `setRowSelectionModel([])`；单行删除后从模型里过滤掉该 id。
  - 用 `useMemo` 生成 `columns`，依赖 `[fields, editingCell, cellSaving, renderCell, sortableFields]`。选择状态不得进入该依赖。
  - `sortableFields` 也要 `useMemo`（依赖 `[fields]`），否则每次渲染都是新数组，列缓存会失效。
  - `renderCell`、`startEdit`、`saveCell`、`openAttachment`、`removeRecord`、`onSort`、`onSortClear` 用 `useCallback` 稳定化。
  - `pinnedLeft` 改为 `['__check__', ...keys]`；`rowKey` 不再传（DataTable 默认用 `row.id`）。
  - 删除传给 DataTable 的 `sx={{ '& .MuiDataGrid-cell[data-field="__select"]': ... }}`。
  - DataTable 增加：
    ```tsx
    checkboxSelection
    rowSelectionModel={rowSelectionModel}
    onRowSelectionModelChange={setRowSelectionModel}
    ```

  - 实现偏差：按设计实测后，`editingCell`/`cellSaving` 已移入 `web-react/src/components/table-edit-store.ts`，由 `web-react/src/components/TableCell.tsx` 通过 `useSyncExternalStore` 订阅；列定义不再依赖编辑状态，`TableCellEditor` 不再需要 `row`。这样双击打开编辑器只重渲染当前单元格。
