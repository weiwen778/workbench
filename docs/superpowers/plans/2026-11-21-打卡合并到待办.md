# 打卡合并到待办与待办文件夹 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用周期待办替代打卡，把待办升级为「文件夹 → 清单 → 任务 → 子任务」的工作台，并保留旧打卡历史只读归档。

**Architecture:** 后端在 `todos` 上增加重复字段，新增 `todo_folders` 与 `checkin_todo_migrations`；完成重复任务时生成下一条链式任务。旧打卡写接口统一返回 410，新归档接口只读且不触发生成。前端把 `Todos.tsx` 拆成左栏文件夹树和右栏任务区，新增只读归档页。

**Tech Stack:** FastAPI + SQLAlchemy 2 + Alembic + Pydantic v2；React 18 + TypeScript + MUI 6 + dnd-kit；pytest + Playwright。

**Spec:** `docs/superpowers/specs/2026-11-21-打卡合并到待办-design.md`

## Global Constraints

- 层级固定为「文件夹 → 清单 → 任务 → 子任务」，不做无限嵌套。
- 计数统一为**未完成的顶层任务**；子任务不计入清单/文件夹/头部/分组数量。
- 重复任务不能有子任务；重复任务完成时只生成一条下一条，不补历史欠账。
- 月重复保留 `repeat_anchor_day`：1/31 → 2/28 → 3/31。
- 周/月任务的截止时间是周期最后一天；新建未填日期时：每天今天、每周本周日、每月本月最后一天。
- 旧打卡数据只读：不修改 `checkin_instances`，旧写接口返回 410，新归档接口不调用生成逻辑。
- 「日常打卡」是普通清单，可重命名/删除；历史归档入口在待办全局工具栏。
- 内容区间距 10px；沿用 Inter、近黑主色、Lucide 图标。
- 不提交 `scripts/ui-probe.js`。

## Review Focus

- **月末跨短月**：1/31 的月重复在 2 月必须落在 28/29，3 月必须回到 31，不能永久漂移。
- **完成链**：重复任务重复提交完成只能生成一条下一条；取消完成时若下一条已开始，必须拒绝而不是留下两条未完成任务。
- **迁移幂等**：迁移脚本重复执行不能重复创建「日常打卡」、文件夹或 45 条规则任务；归档对象不能迁移。
- **归档冻结**：归档页和旧 GET 不能生成新的 `checkin_instances`，旧历史总数保持 10,230。
- **删除/恢复**：删除文件夹不能删清单/任务；回收站恢复必须保留 `folder_id` 和重复字段。
- **筛选与定位**：手动排序不显示日期分组；`?focus=` 必须能定位到未来或已完成任务。
