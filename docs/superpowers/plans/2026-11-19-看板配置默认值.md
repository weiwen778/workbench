# 看板配置默认值修正（P0）实施计划

> **For agentic workers:** 本计划由当前会话直接执行；每个任务按步骤实现并验证。

> 执行记录：任务已在工作区完成，2026-11-20 与表格、操作栏改动一起合并提交。

**Goal:** 修正看板三类会产出错误结论的默认值：时间轴排序、饼图分组、任务进度完成条件。

**Architecture:** 排序在后端聚合层统一纠正 `bar`/`line` 的日期分组行为，前端同步默认值与控件可见性；饼图与进度只改前端配置模型和编辑器门槛，后端校验保持不变。

**Tech Stack:** FastAPI + SQLAlchemy + pytest（后端）；React + MUI + TypeScript（前端）。

**Spec:** `docs/superpowers/specs/2026-11-19-看板配置默认值-design.md`

## Global Constraints

- 不改数据库结构，不做数据迁移。
- 不修改已有饼图的用户配置。
- 进度任务模式仍必须由后端校验 `completed` 非空。
- 视觉间距问题不在本次范围。

## Review Focus

- 日期分组柱状图在 `limit` 小于分组数时，应显示最近 N 组而不是销售额最高的 N 组。
- 多系列柱状图（`value_fields` 多项）与单系列必须使用同样的时间截断规则。
- 饼图默认分组在没有勾选/单选列时应回退到文本列，最后才是日期列。
- 完成任务条件为空时，预览与保存都必须被拦截，不能只依赖后端 422。
- 表格没有状态列时，进度编辑器要给出可执行的替代方案（数值累计），而不是空白。
