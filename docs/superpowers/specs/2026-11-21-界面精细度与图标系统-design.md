# 界面精细度与图标系统 · 设计

日期：2026-11-21
状态：已回退（2026-11-21）。深墨绿侧栏 + 衬线标题 + 黄铜方案被用户否决，代码已恢复到上一轮「界面收口」；本文件仅作记录。
范围：`web-react/src/app/theme.ts`、`icons.tsx`、`layout/AppRail.tsx`、`layout/AppLayout.tsx`、`layout/ModuleTabs.tsx`、`layout/app-nav.ts`、`pages/Checkin.tsx`、`components/TableView.tsx`、`pages/Memos.tsx`、`styles/layout.css`

## 为什么改

上一轮解决的是结构和噪音，功能更好用，但视觉精度仍停在「能用的后台」：12–13px 的中文、1px 边框 + 6px 圆角的统一白卡、Material filled/outlined 混用、14–20px 随意缩放的图标。用户要的是同一套功能下的「精美」，不是新功能、不是今日驾驶舱。

## 目标

- 同一信息架构下，让界面看起来像被设计过：尺度、层次、字体、图标、控件细节统一。
- 图标统一为 24px 网格、1.5px 描边的线稿体系；7 个导航图标定制，其余用 Phosphor Regular。
- 侧栏改成墨绿整高；画布改成冷纸色；标题用衬线；内容密度保持。
- 触屏、键盘、读屏、暗色模式、减少动效全部继续可用。
- 先做打卡、表格、便利贴三个样板页，确认精细度后再铺其他页面。

## 非目标

- 不加「今日驾驶舱」或任何新路由/新功能。
- 不改后端接口、数据结构、业务逻辑。
- 不重写表格、笔记、文档编辑器。
- 不一次性更换所有页面里的直接 MUI 图标；先覆盖壳层、导航和三个样板页。

## 反目标

- 为了「高级」把表格密度拆掉，牺牲一屏信息量。
- 用大面积渐变、玻璃拟态、彩色阴影制造廉价精致感。
- 图标只换库不换尺寸/颜色/对齐，结果仍然混杂。
- 隐藏操作导致触屏或键盘用户找不到入口。

## 设计

### 1. 色彩

| 角色 | 浅色 | 暗色 |
|---|---|---|
| 画布 | `#EEF1EC` | `#0F1513` |
| 内容面 | `#FFFFFF` | `#18211E` |
| 面板/表头 | `#F4F6F1` | `#1E2A25` |
| 墨线 | `#D7DDD5` | `#2A3732` |
| 主文字 | `#17211E` | `#E7EEE9` |
| 次文字 | `#5A6A63` | `#A7B5AD` |
| 禁用 | `#8A9792` | `#7E8F86` |
| 墨绿侧栏 | `#0F3A33` | `#0B2924` |
| 黄铜 | `#A9834A` | `#C6A15B` |
| 错误 | `#B4472F` | `#E07062` |

主色仍使用用户可配置的主题色；黄铜只用于侧栏选中、便签/印章类细节，不抢主操作。

### 2. 字体

- 展示：`Noto Serif SC` / `Noto Serif CJK SC` / `Songti SC` / `STSong` / `SimSun` / serif。
- UI：`IBM Plex Sans Variable` + Noto Sans SC 回退。
- 数字：`IBM Plex Mono`，`tabular-nums`。
- 页面标题 24/600（手机 18），衬线；区块 15/600 无衬线；正文 13.5/1.7；元信息 12/1.55；表格 12.5；数字列等宽。
- 衬线只出现在页面标题、设置分区标题、便签标题、笔记阅读标题和品牌字标；常规区块、控件和表格保持无衬线。

### 3. 布局与表面

- 侧栏：宽 232px，窄 76px（窄版只留图标 + Tooltip）；墨绿底、米白字、黄铜选中态；选中是 32px 图标底板 + 左侧 2px 黄铜短线，不再整行实心。
- 顶栏：56px，画布底色 + 1px 墨线；页面标题就是模块切换入口；搜索是 220px 的「命令条」，不是灰色胶囊。
- 表面三层：画布 → 面板/表头 → 白色内容；卡片 1px 墨线、6px 圆角、无阴影；浮层才用阴影。
- 控件 36px 高、4px 圆角；按钮 32/36；表格行 36；打卡/任务行 56；页面留白 24（密集页 20）。

### 4. 图标系统（方案 A）

- 24px 网格、1.5px 描边、圆角端点、2px 内边距。
- 7 个定制导航图标，每个「线稿 + 一个实心细节」：打卡=日历+实心勾；表格=网格+实心表头格；待办=清单+实心勾选框；笔记=页面+实心折角；便利贴=便签+实心折角；看板=坐标+实心最高柱；文档=纸叠+实心首页。
- 其余工具图标用 `@phosphor-icons/react` Regular，通过 `@/icons` 语义出口统一包装：`sx.fontSize` 控制大小，`currentColor` 控制颜色。
- 尺寸只留 16（行内）/18（工具条、行操作）/20（导航）/24（空状态）；不再出现 14/15/17。
- 品牌标：黄铜方印 + 衬线 N；宽版配 `Nexus` 衬线字标，窄版只留方印。
- 当前头像 logo 保留在 favicon/登录页，侧栏先换方印；如果用户更想保留头像，再按同一套线稿重画。

### 5. 样板页

- **打卡**：今日/本周/本月改成纸面分段控件；分组头用浅面板 + 3px 黄铜短线；行高 56；备注图标有备注时用黄铜；统计数字等宽。
- **表格**：去掉全表竖向分割线，只留横向细线；表头浅面板 + 下墨线；数字列表头/内容同基线；操作列 76px，行操作 hover/focus 出现；主按钮墨绿。
- **便利贴**：保留彩色纸面，降低饱和度；标题改衬线 17；卡片内边距 14；操作图标 18；底部元信息 12；列表视图日期用次文字色。
