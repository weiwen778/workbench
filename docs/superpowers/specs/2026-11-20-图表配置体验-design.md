# 图表配置体验优化设计

日期：2026-11-20
状态：已完成（2026-11-20）

## 背景

看板图表编辑器目前已经是左右布局，但左栏固定 340–400px、弹窗只有 1200px，右侧预览占比偏小；窗口稍窄时两栏直接堆叠。同时图表的默认配色把工作台主题主色放在第一位，用户改主题色会连带改变所有未单独配色的图表，不适合作为数据图表的默认视觉。

## 目标

1. 图表编辑器明确分为「左侧配置 / 右侧实时预览」两栏，预览在滚动配置时保持可见；窄屏才上下堆叠。
2. 图表默认配色与工作台主题色解耦，不再把主题主色塞进图表色板。
3. 在「数据颜色」区域提供「随机配色」按钮，一次为当前所有颜色目标生成一组可区分、明暗主题都可读的颜色，可反复点击重新随机。
4. 保留现有「恢复默认」和逐个颜色选择的能力。

## 非目标

- 不改图表数据结构、看板 JSON、服务端聚合逻辑或数据库。
- 不把配置流程改成向导、分步表单或抽屉。
- 不改 `2026-11-19-看板配置默认值-design.md` 已完成的默认值/排序/进度必填逻辑。
- 不为其他页面（表格、白板等）引入随机配色。

## 现状

- 编辑器：`web-react/src/pages/Dashboard.tsx`，`Dialog maxWidth="lg"`，内容区 `md` 及以上为 `minmax(340px, 400px) minmax(0, 1fr)`。
- 渲染：`web-react/src/components/DashboardChart.tsx`，使用 `@mui/x-charts`。
- 默认色板：`web-react/src/dashboard.ts` 的 `chartPalette(primary)` 返回 `[primary, ...CHART_COLORS]`；指标卡/进度条另有主题主色回退。

## 方案

### 1. 两栏编辑器

- 弹窗宽度改为 `maxWidth="xl"`，`fullWidth` 保持。
- 内容网格在 `md` 及以上改为 `minmax(0, 5fr) minmax(0, 6fr)`：左侧配置约 45%，右侧预览约 55%。
- 右侧预览 `Paper` 在 `md` 及以上 `position: sticky; top: 0`，左栏滚动时预览保持可见；`xs` 仍为单列上下堆叠。
- 预览区最小高度提高，空状态在预览区内居中，避免指标卡预览时右栏显得空。

### 2. 默认配色解耦

- `dashboard.ts`：移除 `chartPalette(primary)` 的 `primary` 首色；默认色板固定为 `CHART_COLORS`。
- 柱状图、折线图、饼图未单独配色时都从 `CHART_COLORS` 按索引取色。
- 任务进度未单独配色时使用 `CHART_COLORS[0]`，不再回退 `primary.main`。
- 指标卡未设置颜色时继续使用正文颜色（本来就不是主题主色），编辑器色块和说明文案改为反映真实默认值。
- 已保存但没有 `colors` 的图表会跟随新默认色；已有自定义颜色的图表不受影响。

### 3. 一键随机配色

- 在 `dashboard.ts` 新增纯函数 `randomChartColors(count, mode)`：
  - 以随机色相为起点，按黄金角步进分散色相；
  - 饱和度/明度带少量随机抖动；
  - 浅色模式用较深、较高饱和的颜色，深色模式用较亮、较柔的颜色；
  - 生成后检查与当前背景（浅色 `#FFFFFF` / 深色 `#171F22`）的对比度，不足 3:1 时继续调整明度，避免黄绿色在浅色背景上看不清；
  - 输出 `#RRGGBB` 大写十六进制，数量限制在 1–30。
- 编辑器「数据颜色」标题右侧增加「随机配色」按钮：
  - 指标卡/进度：生成 1 个颜色；
  - 饼图/柱状图/折线图：生成 `max(当前颜色目标数, 8)` 个颜色，预览尚未加载时也有可用色板；
  - 写入 `form.colors`，覆盖当前自定义颜色；再点一次重新生成。
- 「恢复默认」继续保留，清空 `form.colors` 后按新默认色板显示。

## 取舍

- 继续用两栏而不是向导：随机配色和实时预览都依赖快速看到结果，分步会打断“选列 → 看图形”的反馈循环。
- 随机生成而不是从固定色板洗牌：每次点击都有变化；固定 S/L 范围避免出现不可读的荧光色或灰到看不清的颜色。若之后想要“只在精选色板里随机”，只需替换 `randomChartColors` 的内部实现。
- 默认色板完全不带主题色：这是本次明确的产品选择，代价是用户改主题色时图表外观不再联动。

## 影响面

- 纯前端：`web-react/src/dashboard.ts`、`web-react/src/pages/Dashboard.tsx`、`web-react/src/components/DashboardChart.tsx`。
- 看板 JSON 结构不变，服务端与旧数据兼容。
- 未自定义颜色的旧图表会呈现新的默认色，这是预期行为。

## 验收点

1. 1440px 宽度下打开「添加图表」：左配置、右预览并排，滚动左侧时右侧预览保持可见；390px 宽度下上下堆叠。
2. 新建柱状图/折线图/饼图不设置颜色：首色来自独立色板，不再是工作台主题主色；切换主题色后图表默认色不变。
3. 点击「随机配色」：所有颜色目标立即变化；再点一次得到不同的一组；浅色/深色主题下颜色可读。
4. 指标卡不设颜色仍为正文色；进度条默认使用独立色板首色。
5. 已有自定义颜色的图表保持不变。
6. `npm run typecheck` 通过；浏览器人工验收上述场景。
