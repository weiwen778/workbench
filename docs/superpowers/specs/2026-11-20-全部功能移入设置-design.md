# 全部功能移入设置 — 设计

日期：2026-11-20
状态：待确认

## 意图

侧栏底部现在有「全部功能」入口，与「设置」并列。它常用于浏览/固定低频模块，但占用了侧栏最宝贵的底部位置。把它收进设置页，让侧栏只保留高频导航、设置和收起/展开。

## 目标

- 桌面侧栏删除「全部功能」按钮。
- 设置 → 导航 变成完整的「全部功能」面板：搜索、按分组浏览、点击打开模块、固定/取消固定、拖动排序已固定项。
- 移动端仍然可以通过左上角「打开导航」和底部「更多」打开功能抽屉。

## 非目标

- 不改变 `app-nav.ts` 的模块定义和分组。
- 不改变固定项的存储方式（按账号存在 localStorage，经 `sidebar-order.ts`）。
- 不改变移动端底部导航。

## 方案

**采用 A：内嵌到「设置 → 导航」。** 把 `NavigationSection` 扩展为一个完整的全部功能面板，`ManageNavDialog` 的职责并入其中，避免设置页出现两个内容高度重叠的入口。

方案 B（只在设置里放按钮打开旧抽屉）被否：抽屉和管理导航对话框都列全部功能，设置页会出现两个几乎一样的入口。

## 设计要点

1. **`AppRail`**：删除底部「全部功能」`bottomItem`，移除 `onOpenAll` prop。底部只留「设置」和收起/展开。
2. **`AppLayout`**：删除 `allNavOpen` 状态和 `onOpenAll` 传参。`NavAllDrawer` 仍保留，仅由移动端 `drawerOpen` 驱动。
3. **`NavigationSection`**：
   - 保留「侧栏宽度」卡片。
   - 新增「全部功能」卡片：
     - 搜索框（按模块名过滤）。
     - 已固定项列表，支持拖动排序（复用 dnd-kit 逻辑）。
     - 按分组列出其余模块，点击整行跳转到对应页面；图钉按钮固定/取消固定。
     - 「恢复默认」按钮。
   - 打开模块时使用 `useNavigate`。
4. **`NavPanels.tsx`**：`NavAllDrawer` 底部「管理导航」改为跳转 `/settings/navigation`；`ManageNavDialog` 不再被使用，删除该组件及其 DnD 辅助组件（相关逻辑移入 `NavigationSection`）。
5. **文案**：`Settings.tsx` 中「导航」的描述改为「设置侧栏宽窄，浏览全部功能，管理固定项和顺序」。

## 影响与验证

- 更新 `e2e/react-ui-consistency.mjs`：
  - 不再断言侧栏包含「全部功能」。
  - 「管理导航」流程改为进入 `/settings/navigation` 操作。
  - 抽屉相关断言仅保留移动端场景。
- 手动验证：桌面侧栏无「全部功能」；设置 → 导航可搜索、打开模块、固定/取消固定、拖动排序、恢复默认；移动端抽屉正常。
