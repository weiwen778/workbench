# 文档工作台

Nexus 内独立使用的文档工作台：PDF 编辑与处理、工作簿、Markdown 文档。文件读取、解析、渲染、公式计算、转换和导出都在浏览器完成；点击「保存项目」时才把项目元数据、可恢复编辑状态和必要附件提交到 Nexus。

入口：侧栏「文档工作台」→ `/docs`。三个页签：PDF 编辑与处理、工作簿、Markdown 文档。现有「表格」页保留原数据库表格工作流，并新增「打开工作簿」入口进入同一工作簿编辑器。

命名约定：第三个页签是 **Markdown 源编辑**（不是 Word 原生编辑，也不是富文本编辑器），DOCX 走导入导出转换；第二个页签是 Excel 式**工作簿**，与侧栏「表格」（数据库表格）不是同一个东西。

## 3. PDF 编辑与处理

### 打开与阅读

- 拖入/选择 PDF；支持多文件合并。
- 左侧缩略图懒渲染；中间 PDF.js 渲染，支持 35%–300% 缩放、页码跳转、上一页/下一页。
- 文本层可选中复制；工具栏「复制本页文字」；「搜索」跨页搜索并跳转到结果页。
- 破损文件、加密 PDF 有明确错误；首版不支持受密码保护 PDF 的编辑/导出。
- 数字签名字段会显示失效风险提示（检测逻辑已接入，未用真实签名样本做独立验签）。

### 页面整理

- 多 PDF 导入合并；「插入 PDF」在当前页后插入。
- 拖动缩略图重排（dnd-kit），同时提供上移/下移按钮。
- 旋转 90°、复制当前页、删除当前页、按范围删除。
- 抽取指定页：按 `1-3,5` 形式校验范围并导出子 PDF。
- 所有操作围绕页面模型进行；缩略图、预览、导出使用同一页序和旋转值。

### 批注与表单

- 高亮、手绘、文字批注、勾选标记、签名图片。
- 文字批注使用 PDF 坐标保存；旋转页面导出时按页面旋转补偿方向，独立阅读器检查位置一致。
- 表单字段：文本、勾选、下拉、单选、选项列表；读取自 PDF AcroForm。
- 仅在「单一来源 + 页序未变 + 无删密页」时保留可交互表单；合并/重排/删页/删密后给出兼容提示，导出不保留交互字段。
- 数字签名提示：修改可能使原签名失效。
- 撤销/重做覆盖页面顺序和批注；页码、水印和表单填写值是独立设置，不进入页面历史，避免“先加批注再改水印”触发意外回退。可清除当前页批注。

### 页码、水印与输出

- 页码：格式模板 `{page}` / `{total}`、页码范围、位置、字号、颜色、透明度。
- 文字水印：文字、范围、字号、角度、颜色、透明度；支持中文。
- 当前页显示页码/水印预览；导出在最终页序和旋转上绘制。
- 多张图片可上移/下移排序后合成 PDF，并追加到当前文档。
- PDF 指定页可导出 PNG/JPG；单页直接下载图片，多页打包 ZIP。
- 导出 PDF 始终生成新副本，不覆盖原文件。
- 中文、不同页面尺寸、旋转页已在独立渲染器检查；页码/水印/批注位置正常。

### 永久删密

- 工具栏「标记删密」拖出黑色区域；仅标记阶段不改变原 PDF。
- 导出时二次确认；含删密区域的页面用 PDF.js 重新渲染为图片并绘制黑色区域，再完整重写为新 PDF。
- 导出后使用 PDF.js 再次提取删密页文字层；如仍检测到文字则警告。
- 独立验证：含 `REDACT-ME-123` 的测试页导出后 pypdf/PyMuPDF 提取结果为空；未删除页仍可读取。删密页的原文字层、交互表单和链接不保留，其他内容视觉仍可读。
- 该实现是真正的重写/栅格化删密，不是矩形覆盖或仅保存批注；删密页会失去文字层，这是明确的保真代价。

### 未实现 PDF 能力

- 扫描件 OCR / 可搜索 PDF 写回文字层（Tesseract.js）未启用。
- PDF 正文直接改字、PDF 转 Word、深度压缩、加密、数字签名未开放。
- 受密码保护 PDF 只给出错误，不支持密码输入后编辑/导出。
- 数字签名仅做字段检测提示，未做签名验证或保留签名。

## 4. 工作簿

### 导入与编辑

- 编辑内核：Univer 1.5（`@univerjs/presets` + `@univerjs/preset-sheets-core`），提供 Excel 式网格、工具栏、公式栏、多工作表、区域选择。
- 支持导入 XLSX/XLS/XLSB/ODS/CSV/TSV；单文件上限 20 MB；超过 20,000 行 / 500 列的部分会提示并截断。
- XLSX 读写由本地 SheetJS 桥接（`web-react/src/docs/sheet/xlsx-bridge.ts`）：导入单元格值、公式、合并单元格、列宽、行高、数字格式；导出 XLSX / CSV / Univer 快照。
- Univer 官方 XLSX exchanger 属 Pro 版且需要服务端转换，离线工作台不采用；因此不引入任何外部转换服务。
- 单元格样式（字体、字号、颜色、边框、对齐、百分比/货币等数字格式）、合并单元格、冻结窗格、查找替换、排序筛选由 Univer 内核提供，之前 DataGrid 版本缺失的能力在这里补齐。
- 项目保存落两份附件：`*.xlsx`（交付/导出用）与 `*.univer.json`（无损快照）。重开优先用快照，快照缺失时回退解析 XLSX。
- 每次装载（导入或重开）都分配新的 Univer unitId，避免与当前实例冲突。
- 已知差异：SheetJS CE 不读写单元格样式，XLSX 往返会丢样式（用快照重开不丢）；图表、数据透视表、宏、数据验证、批注不迁移。

### 公式

- 公式由 Univer 公式引擎计算（`@univerjs/engine-formula`），支持算术、比较、文本、日期、单元格/区域引用与跨表引用，覆盖 Excel 常用函数。
- 编辑后实时重算；错误值按 Excel 语义显示（如 `#DIV/0!`、`#REF!`）。
- 导出 XLSX 同时写入公式表达式与当前缓存值，供不重算的阅读器显示。
- 兼容提示：宏/VBA 永不执行；图表、透视表、外部链接不迁移。

## 5. Markdown 文档

本页是 **Markdown 源编辑器**（CodeMirror）+ 安全预览，不是 Word 原生编辑，也不提供富文本可视化编辑。DOCX 只能整体转换成 Markdown 再编辑，导出的是一份**新生成的 DOCX**，不是原文件另存。

### 导入

- DOCX → Mammoth 安全 HTML → 清理 → Turndown → Markdown 编辑内容。
- 支持标题、段落、列表、基础表格、图片、粗体/斜体/链接/代码等常用格式。
- 导入前提示：页眉页脚、分页、复杂表格、浮动对象、修订记录可能与 Word 不同。
- TXT、Markdown 直接编辑。
- HTML 经 DOMPurify 清理，移除脚本、iframe、样式表、远程/协议相对图片、`srcset`/`poster` 和所有内联 `style`；链接保留并加 `noopener noreferrer`。
- DOC/RTF/ODT 未开放。

### 编辑与预览

- 复用笔记的 CodeMirror Markdown 编辑器和主题。
- 左侧 Markdown 源编辑、右侧安全预览；可切换编辑/分栏/预览。
- 工具栏：H1/H2、粗体、斜体、列表、编号、表格模板、图片、查找替换、复制 Markdown、撤销/重做。
- 图片可选择本地图片插入为 data URL；保存项目时上传为附件并替换为 Nexus 文件 URL。
- 预览和导出都使用同一套清理后 HTML；Markdown 中的远程图片不会自动加载。

### 导出

- DOCX：复用 `note-export` 的 docx 生成，保留标题、段落、列表、表格、图片、链接；导出新的 DOCX（不直接改原文件）。
- HTML：带工作台打印 CSS 的完整 HTML。
- Markdown / TXT：直接下载编辑内容/纯文本。
- PDF：复用 `note-export` 的 `html-to-image` + jsPDF 流程，按内容分页；长表格/图片会按安全切点分段。
- 打印预览：对话框内显示实际 HTML，可调用浏览器打印，也可导出 PDF。
- 浏览器 PDF 导出为栅格化输出，文字不可选中；这是已知的保真差异。
- 独立验证：python-docx 读取导出 DOCX，确认中文段落、列表、表格、图片；PyMuPDF 渲染 PDF 检查中文/分页/表格。

## 6. 项目保存与恢复

### 后端

新增 `document_projects` 表（迁移 `20261114_e8f9a0b1c2d3_document_projects.py`）：

- `id`、`user_id`、`kind`（pdf/sheet/document）、`title`、`state` JSON、`version`、`created_at`、`updated_at`。

接口（均需登录，按用户隔离）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/document-projects?kind=` | 当前用户项目列表 |
| GET | `/api/v1/document-projects/{id}` | 项目详情和可恢复 state |
| POST | `/api/v1/document-projects` | 创建项目，附件 ID 建立引用 |
| PUT | `/api/v1/document-projects/{id}` | 更新项目；版本冲突 409 |
| DELETE | `/api/v1/document-projects/{id}` | 删除项目并释放附件引用 |

- 附件沿用现有 `/api/v1/files`、`FileObject`、`FileRef` 和容量限制；`FileRef.owner_type='document_project'`，上传文件记录 `owner_id`。
- 项目附件保存后标记为 `bound`；读取时校验项目归属。同一账号的“另存为新项目”可共享附件，其他账号、笔记或表格已引用的附件不能被项目占用。
- 删除或替换项目附件时释放引用；失去全部引用的文件回到 `staged` 并在 TTL 后清理。
- state 最大 5 MB；附件沿用单文件 20 MB 上传限制。
- 项目保存失败保留当前内存编辑；可重试；并发版本冲突提供「另存为新项目」。
- PDF 项目保存原始 PDF 附件 + 页序/旋转/批注/表单/水印 state；表格保存当前 XLSX 附件 + 工作表选择；文档保存 Markdown + 图片附件。
- 未点击「保存项目」的文件只留在浏览器内存，不上传。文档页签会每 700ms 将未保存内容写入浏览器本地草稿（上限 4 MB，可在横幅恢复或丢弃）；PDF/工作簿没有二进制自动草稿，刷新前需保存项目或导出。关闭/刷新有未保存内容时会触发浏览器离开提示。
- 超过上传上限的 PDF 仍可在本地打开、编辑和导出；保存项目时会提示附件失败，不会覆盖原文件。

## 7. 安全与本地处理

- 文件处理全部在浏览器：PDF.js、pdf-lib、SheetJS、Mammoth、marked、DOMPurify、jsPDF 均不主动上传文件。
- 文档 HTML 清理：禁止 script/iframe/object/embed/form/style/link/base，移除事件属性、所有内联样式、`srcset`/`poster` 和站外图片；导出使用清理后的 HTML。
- `/docs` 三个编辑器按页签懒加载：默认只加载 PDF 编辑器，表格/文档页签首次打开时才加载各自依赖。
- 工作簿宏不执行；不计算公式中的外部链接/宏；导出不保留 VBA。
- PDF 数字签名修改提示；删密采用重写/栅格化而非覆盖。
- 项目附件读写通过 Nexus API，使用现有会话、CSRF 和文件权限；项目列表和详情按 `user_id` 过滤。
- 浏览器网络面板检查：导入、编辑、公式重算、PDF 批注、文档预览均无外部请求；只有点击保存项目才提交 Nexus API，导出图片/PDF 使用本地 Blob 下载。

### 独立校验工具

- PDF：`pypdf 7.1.0` 与 `PyMuPDF`（临时验证 venv）检查页数、旋转、文本、删密、渲染。
- XLSX：`openpyxl 3.1.5` 检查工作表、公式、缓存值、日期、前导零。
- DOCX：`python-docx 1.2.0` 检查段落、表格、图片。
- 环境没有 LibreOffice/Word/Adobe Acrobat，因此改用上述独立库 + MuPDF 渲染；真实 Word/Excel UI 打开仍需在目标办公环境补验。

## 9. 已知限制与未验证项

### PDF

- 删密页必须栅格化；未删区域视觉可读，但该页文字层、链接、表单和文本选择丢失。
- 文字批注/页码/水印使用内置 Noto Sans SC 常用字子集；极少数生僻字可能缺字。为兼容独立阅读器，导出时整字体嵌入，含文字叠加的 PDF 会增加约 1.4 MB。
- 表单交互只在单来源、原页序、无删密页时保留；合并/重排/删页后表单值不保留，界面会提示。
- 受密码保护 PDF 不支持阅读/编辑/导出（仅明确错误）。
- 未实现 OCR、可搜索 PDF 写回文字层、正文直接改字、PDF 转 Word、压缩、加密和签名。
- 数字签名只检测并提示，未验证真实签名文件是否保留/失效。

### 工作簿

- 公式由 Univer 引擎计算，覆盖 Excel 常用函数与跨表引用；极少数新函数仍可能不支持。
- XLSX 往返不保留单元格样式（SheetJS CE 限制）；需要无损重开时用项目快照。
- 多级表头、图表、数据透视表、数据验证、批注不迁移；宏永不执行。
- XLS/XLSB/ODS 导入后统一导出 XLSX，不提供另存回原格式。
- 超大表格上限为 20 MB，超过 20,000 行 / 500 列的部分会截断并提示。

### 文档

- DOCX 通过 Mammoth → Markdown 转换，非原生高保真编辑；页眉页脚、分页、复杂表格、浮动对象、修订记录、批注会丢失。
- 导出为新 DOCX，不直接修改原 DOCX。
- DOC/RTF/ODT 未开放。
- 文档 PDF 导出为栅格化图像，文字不可选中；打印预览使用浏览器打印。
- Markdown 只支持实际解析/清理后的语法；远程图片不自动加载。

### 通用

- 项目附件沿用 Nexus 单文件 20 MB 上限；PDF 本地允许 100 MB，但超过 20 MB 的源文件保存项目会失败，可继续导出。
- 文档页签有 4 MB 浏览器本地草稿；PDF/工作簿没有二进制自动草稿，未保存项目刷新会丢失内存内容。保存项目后重开可恢复。
- 仅在 Chromium 验证；未在 Safari/Firefox 或真实 Office/Acrobat 中验收。
- 没有多人实时协作。
