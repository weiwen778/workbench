# AI 图片填表

入口：表格 → 原始表 → AI 图片填表。打开弹窗后可在当前页面任意焦点粘贴 PNG/JPG 截图，也可点击或拖入图片；图片加入后自动识别，无需点击开始。默认 GLM-4V-Flash，模型切换与双模型对比开关统一放在设置。结果按当前表字段生成核对表单，手动修正后「确认新增」才写入业务数据，不覆盖已有行。切换结果时保留各自手动修订。支持竖排字段/值、横排多条记录，每次最多 50 条。附件、关联和计算字段不交给模型填写。

设置 → AI 图片填表：配置智谱 API Key、默认模型和「识别时同时对比两个模型」开关。Key 使用现有 Fernet 主密钥加密保存，只返回是否配置，不返回原值。密钥留空保留已有值，清除后两个模型均不可调用。生产部署需要 WB_ENCRYPTION_KEY，并执行 Alembic 迁移 a3b4c5d6e7f8。

## 实现

参考 customr_crm 的服务端代理、白名单校验、核对后保存流程，改为动态读取当前表字段。GLM-OCR 使用 `/api/paas/v4/layout_parsing`，HTML/Markdown 结果由 Beautiful Soup 解析并映射现有字段；GLM-4V-Flash 使用 `/chat/completions`，字段结构写入提示词，JSON 输出再校验。两者统一执行选项名称→ID、日期格式和字段类型校验；手机号保持文本，缺失项不猜测。没有匹配字段或格式不合法时提示核对。上游错误不透传响应体或 Key，截断内容与超 50 行明确报错。

图片最大 8 MB / 2500 万像素，不保存原图；发送至智谱 API。网络等待前释放 DB 事务，最多两个重请求并行。草稿加密，24 小时内可确认，过期的 pending 草稿在后续识别时清理。确认仅允许浏览器用户会话、校验用户归属/目标表/字段版本，整体事务写入并生成表格历史。重复确认返回同一批记录 ID。Agent 不能通过此入口绕过人工确认。

## 本地实测（2026-11-04）

用户提供截图，真实「测试1」表：姓名、年龄、性别、地址、手机号、邮件、日期。使用完全相同的图片与字段配置，执行 3 轮调用，每轮 7 字段。所有结果先预览，不向真实表新增记录。

| 模型 | 正确字段 | 平均调用耗时 |
| --- | --- | --- |
| glm-ocr | 21/21 | 1.59 秒 |
| glm-4v-flash | 21/21 | 2.07 秒 |

结果为张三、76、男、中国广东、1120023331、123@asda.com、2034-01-03。当前样图正确率持平，GLM-OCR 平均更快；当前默认模型按使用偏好配置为 GLM-4V-Flash；这仅是清晰截图的小样本结果，不能推断所有文档、手写或复杂布局的优劣。耗时包含网络延迟。使用费用和并发限制以用户智谱账号为准。

## 弹窗快捷键

打开期间在 window 捕获图片 paste 事件，Ctrl/⌘+V 无需先点击上传区。Ctrl/⌘+Enter 确认新增，Esc 关闭（未保存结果需确认放弃）。弹窗关闭或组件卸载即移除监听；普通文字粘贴仍按输入框原生行为处理。只在当前工作台页面内生效。新图片会中止旧前端请求，使用序号隔离迟到结果，避免覆盖新图片的表单。左侧图片、右侧表单独立布局，内容在弹窗内滚动。
