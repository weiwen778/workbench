# Workbench Web (React + MUI)

这是个人工作台（Workbench）的当前前端：**React 18 + TypeScript + MUI 6 + Vite**，数据表格使用 MUI X DataGrid，图表使用 MUI X Charts，后端保持不变。

## 开发

```bash
cd web-react
npm install
npm run dev        # http://127.0.0.1:5174，/api 代理到 127.0.0.1:18080
```

## 构建与部署

```bash
cd web-react
npm run build      # 产物输出到 ../web/dist（后端仍从 web/dist 托管）
```

构建产物会自动被现有后端同源托管，因此无需修改 API、数据库或静态文件路径。`npm run build` 同时生成 `.br` / `.gz` 预压缩文件。

Docker 构建使用 `web-react/Dockerfile`；`docker-compose.yml` 的 `web` 服务已指向该文件。

## 目录

```
src/
  api/          Axios 客户端（CSRF、错误格式）
  app/          MUI 主题（工作台账风格：青绿主色、IBM Plex 字体、直角、紧凑密度）
  components/   表格、记录抽屉、导入、工作簿、图表等
  layout/       AppLayout、左侧图标栏 AppRail、顶部模块下拉选择 ModuleTabs
  pages/        登录、打卡、待办、表格、笔记、便利贴、看板、翻译、图片、设置等
  ui/           通用 UI 与 Toast / 对话框
  utils/        导出、图片处理、文本偏好
  session.ts    会话与主题状态
  table-core.ts 表格显示/汇总工具
```

## 导航设计

- 默认首页是「打卡」；旧地址 `/today` 自动跳转，情报模块已移除。
- 全局只有左侧 84px 图标栏一条侧边栏；模块内的清单、表格、看板、分类等收在顶部下拉选择中，右侧 `+` 新建当前模块项目。
- 表格页支持快速新增行和单元格内联编辑：点击单元格直接修改，回车保存、Esc 取消。
- 表格页的「AI 填入」支持上传 PNG/JPG 截图、Ctrl/⌘+V 粘贴截图或粘贴杂乱文本，按当前字段识别、人工核对后写入；常见联系方式/资料文本走本地快速识别（毫秒级），复杂文本再交给智谱模型。
- 图片处理采用左侧图片队列、中间预览、右侧「分类图标栏 + 折叠工具卡」的沉浸式布局；分类包括调整、色彩、标记、文字、拼图、切图、导出；支持电商平台尺寸预设、裁剪旋转、角度校正、高质量放大、调色滤镜、颜色叠加、纯色去底、涂鸦/矩形/马赛克标注、文字水印、拼图、宫格切图和批量 ZIP 导出；全部在浏览器本地完成，图片不上传。图片始终按原始比例缩放，画布比例不同时只留白或裁边，不会拉伸变形。
- 设置 → Agent 接入提供三步引导：创建细粒度权限令牌、复制接入说明/接口地址/配置、在暂存区按状态筛选并查看字段差异，支持重新预览、单个或批量通过、驳回。
- 翻译支持百度、有道、DeepSeek、智谱 GLM、OpenAI 兼容接口、DeepL、MyMemory（免密钥）和 LibreTranslate；智谱可直接复用「AI 能力」里的 Key，OpenAI 兼容可填自建或第三方 Chat Completions 地址。翻译页会提示未启用服务、显示字数进度、支持 Ctrl/⌘+Enter、收藏去重和一键清空历史。
- 看板支持「AI 生成」：输入一句话描述想看的数据，自动生成 1–4 个图表配置并逐张预览，确认后添加到看板；手动添加图表改为单页配置 + 实时预览，日期筛选、单位、数量等收进「高级设置」。
- 移动端使用底部导航（打卡 / 待办 / 表格 / 更多），更多打开完整导航抽屉。
- 全局 `Ctrl / ⌘ + K` 或顶栏搜索框打开「统一搜索」弹窗，回车打开第一条结果，Esc 关闭。
- 顶栏任务按钮打开「任务中心 / 操作记录」弹窗；导入、导出提交后台任务后会直接打开该弹窗，不再跳转独立页面。
