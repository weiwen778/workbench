# 前端迁移记录（Vue + Element Plus → React + MUI）

## 已完成

- 工程：Vite + React 18 + TypeScript + MUI 6；产物仍输出到 `web/dist`，后端零改动。
- 全局：工作台账风格主题、暗色模式、强调色；左侧图标栏 + 顶部模块标签条、移动端底部导航、全局搜索、任务角标。
- 首页「情报台」：百度/头条/36氪/V2EX 热榜，少数派/IT之家/爱范儿/Solidot/BBC/阮一峰资讯，上证/深证/恒生与汇率，深圳天气；工作台入口保留。
- 页面：登录、打卡（周期/状态/项目筛选、完成/取消、备注、历史、导入、项目管理、分类管理）、打卡项目资料与任务、待办（清单、子任务、排序、完成、编辑、删除）、数据表列表与数据表（筛选、排序、分页、批量删除、列设置、记录抽屉、导入、导出、汇总、删除前备份、快速新增行、单元格内联编辑、AI 图片/乱文本填表）、数据可视化（指标/柱状/折线/饼图/任务进度、时间筛选、AI 自然语言生成图表、单页实时预览、编辑与预览）、笔记（文件夹/标签、Markdown 编辑、自动保存、冲突处理、历史版本、图片插入、HTML/PDF/PNG/DOCX 导出）、便利贴、翻译（百度/有道/DeepSeek/智谱/OpenAI 兼容/DeepL/MyMemory/LibreTranslate、服务选择、收藏、历史、详情）、网址导航（分类、测速、元数据解析）、图片处理（尺寸/电商预设/裁剪旋转/角度校正/高质量放大/调色滤镜/颜色叠加/纯色去底/涂鸦标注/矩形/马赛克/文字水印/拼图/宫格切图/批量 ZIP）、任务中心与操作记录弹窗、设置（外观、账号、Agent、AI、翻译服务、回收站、备份与运行状态）。
- API 兼容：沿用 `/api/v1`、CSRF、Cookie 会话与现有错误结构；沿用 `wb:*` 事件做跨页面刷新。

## 已知差异 / 待补齐

1. **图片标注**：画笔、画框、马赛克尚未迁移；文字水印、纯色去底、调色、尺寸、批量导出可用。拼图 UI 未迁移。
2. **汇总与透视**：当前为分组汇总/交叉透视的简化版（客户端计算），未接入 VTable PivotTable 的完整交互。
3. **工作簿**：已支持核心编辑与保存、Excel/JSON 导入导出、原表快照；本机未保存恢复、打印、查找替换快捷键、另存为独立文件尚未迁移。
4. **Agent 变更审核**：支持令牌权限细分、接入引导、状态筛选/搜索、变更详情与字段差异、重新预览、通过/驳回和全部通过；拆分变更尚未迁移。
5. **笔记/翻译分栏**：布局固定，未提供拖拽调整分隔条；其他核心功能可用。

## 回滚

旧前端源码保留在 `web/src`。如需回滚：

```bash
cd web && npm ci && npm run build   # 重新生成 Vue 产物到 web/dist
```

或使用旧镜像定义 `web/Dockerfile`。
